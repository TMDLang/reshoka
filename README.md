# Re:shoka — 日治時期臺灣公學校與小學校唱歌教材數位重建計畫

**Re:shoka** 是一項將日治時期（1910–1930 年代）臺灣校園音樂教材重新數位化與有聲化的計畫。本專案整理了當時學童實際傳唱的《公學校唱歌》與《新定兒童唱歌》等教材，將原本僅存於博物館典藏庫中的靜態掃描圖檔，轉化為**可以在網頁上直接聆聽伴奏、閱讀五線譜、檢索歌詞與瀏覽統計資料**的開放資料庫。

---

## 一、專案目的

1. **讓百年前的課堂歌聲重新被聽見**：日治時期針對臺灣公學校（臺籍學童就讀）與小學校編纂的唱歌教材，過去多半只有紙本或掃描影像留存，一般人若不識譜或沒有樂器，很難想像這些歌曲實際聽起來的樣貌。本計畫目前已整理 **439 首**歷史曲目，並為每一首歌編配雙手鋼琴伴奏與合成音訊，讓所有人都能直接試聽。
2. **以純文字格式保存樂譜，方便檢索與再利用**：將歷史樂譜數位化為結構化的純文字樂譜檔，避免受限於特定商業製譜軟體的封閉格式，方便長期保存並轉換為各種現代格式。
3. **從整體數據觀察當時的音樂教材設計**：當這些曲目轉為結構化的數位資料後，就能透過簡單的統計程式，從「調性分布」、「節拍選擇」、「五聲音階與七聲音階的比例變化」以及「歌唱音域寬度」等角度，一窺百年前音樂課本由淺入深的編排方式。

## 三、內容產生過程

本專案透過三個步驟，將百年前的課本掃描頁轉化為現代可以直接使用的數位樂譜與音訊：

```mermaid
flowchart LR
    A["1. 原書掃描圖檔<br/>簡譜・五線譜・日文歌詞"] --> B["2. AI 辨識與校對<br/>讀取音符・節拍・調號與歌詞"]
    B --> C["3. 轉為 TMD 純文字樂譜<br/>建立單音主旋律 ＋ 編配雙手鋼琴伴奏"]
    C --> D["4. 自動轉換為現代格式<br/>輸出 MP3 音訊・五線譜與樂曲分析頁面"]
```

### 1. AI 辨識原書樂譜與歌詞
- **樂譜判讀**：原書低中年級多採用「數字簡譜」，高年級與高等科則採用「五線譜」（包含二部輪唱與合唱譜）。我們先透過多模態 AI 讀取掃描圖檔中的調號、拍號、速度、各小節音高與節奏時值，並人工校對小節數與拍數是否吻合。
- **歌詞轉錄**：同步將原書上的片假名、平假名與漢字歌詞轉為文字（保留當時的歷史假名寫法），並記錄對應的原書頁碼與掃描圖檔，方便讀者直接在網頁上對照原書影像。

### 2. 轉換成 TMD 格式與編配鋼琴伴奏
- **原曲主旋律檔**：將辨識出的單聲部或合唱旋律寫成標準的 TMD 純文字樂譜檔（`.tmd`），並透過工具自動檢查每個小節的拍數是否正確。
- **雙手鋼琴伴奏檔**：原書絕大多數曲目僅印有單行歌唱旋律，沒有伴奏譜。為了讓歌曲聽起來更完整，我們根據每首歌的調性與曲風（例如輕快的童謠、進行曲或抒情合唱曲），為每首曲目另外編寫了包含前奏、右手主旋律與左手和聲伴奏的雙手鋼琴版本（`*_piano.tmd`）。

### 3. 自動輸出為現代格式（MP3、五線譜與網頁）
完成 TMD 樂譜後，由專案內的自動化腳本統一將所有樂譜轉換為一般讀者與音樂軟體可直接使用的現代格式：
- **MP3 伴奏音訊**：將雙手鋼琴伴奏譜合成為音訊檔，讓每首歌的頁面都有內建播放器可直接試聽。
- **互動式五線譜**：將樂譜轉為網頁標準的 ABC 記譜格式（`.abc`），並在瀏覽器中透過 `abcjs` 自動繪製成清晰的向量五線譜。
- **單曲音域與調性報告**：自動分析每首歌的長度、最高音與最低音範圍，以及各個音高的出現比例。

## 四、相關統計資料（目前已整理之 439 首）

以下根據目前已整理的 9 冊、439 首曲目，統計這批教材在**調性**、**節拍**、**五聲音階比例**與**歌唱音域**上的分布：

### 1. 調性統計

- **大調與小調比例**：目前收錄曲目以明亮的大調歌曲為主，共 **385 首（87.7%）**；小調歌曲共 **54 首（12.3%）**。各冊之中，以《新定兒童唱歌・高等科女子一二年用》的小調比例最高，達 **24.2%（15/62 首）**，收錄了較多抒情與敘事曲風的作品。
- **常用調號分布**：高達 **89.5%** 的曲目集中在 2 個升降記號以內的調號。其中 **F 大調** 與 **G 大調** 合計超過一半（**52.4%**），主要是因為這兩個調號能讓主旋律自然落在兒童最容易發聲的中音區：

| 調號 | 升降記號數 | 曲數 | 全體佔比 | 在各年級的分布特色 |
| :--- | :--- | ---: | ---: | :--- |
| **F 調** | 1 個降記號（1♭） | 121 | **27.6%** | 一、二年級最常使用的調號（一年級佔 52.5%、二年級佔 31.9%） |
| **G 調** | 1 個升記號（1♯） | 109 | **24.8%** | 四年級至高等科最常使用的調號（高等科男子佔 38.7%） |
| **C 調** | 無升降記號 | 78 | **17.8%** | 各年級皆有分布，常用於儀式歌與第三學期曲目 |
| **D 調** | 2 個升記號（2♯） | 52 | **11.8%** | 常見於開闊明亮的自然景致與行進曲目 |
| **降 B 調（Bb）** | 2 個降記號（2♭） | 33 | **7.5%** | 自二年級起逐步出現 |
| **降 E 調（Eb）** | 3 個降記號（3♭） | 26 | **5.9%** | 多見於中高年級與海景、抒情曲目 |
| **A / E / 降 A 調** | 3♯ / 4♯ / 4♭ | 20 | **4.6%** | A 調 14 首（3.2%）、E 調 5 首（1.1%）、降 A 調 1 首（0.2%） |

- **整體速度**：平均速度為每分鐘 **98.9 拍（BPM）**，中位數為 **100 BPM**（最慢 54 BPM，最快 168 BPM），貼近兒童步行與自然呼吸的律動。
- **拍號按年級循序引入**：一年級與二年級 **100% 只使用單純的二拍子（2/4 拍）與四拍子（4/4 拍）**；三拍子（3/4 拍）與六八拍（6/8 拍）則是到了**三年級**才開始出現，展現了非常清楚的節奏教學順序：

### 3. 五聲音階與七聲音階的比例變化

日本明治、大正至昭和初期的學校唱歌，大量採用省略第四音（Fa）與第七音（Ti）、僅由 **Do、Re、Mi、Sol、La** 五個音組成的五聲音階（日文稱為「ヨナ抜き音階」）。統計目前已整理的 439 首歌各個音級的時值比例後，可以看到教材隨年級升高，從「五聲音階」逐步過渡到「西洋七聲音階與轉調樂曲」的明顯趨勢：

- **各音級的平均使用比例**：
  - 五聲骨幹音：**Do（21.3%）**、**Sol（21.3%）**、**Mi（20.0%）**、**Re（17.2%）**、**La（12.5%）**——這五個音合計佔了總音符長度的 **92.3%**。
  - 半音傾向音：**Fa 平均僅佔 3.8%**（有 175 首歌完全沒用到 Fa）、**Ti 平均僅佔 3.5%**（有 193 首歌完全沒用到 Ti）。

### 4. 歌唱音域統計

- **整體音域寬度**：目前已整理的 439 首曲目平均音域跨度為 **14.0 個半音（約一個八度加一個全音，即大九度）**，中位數同為 **14 個半音**。
- **音域集中範圍**：
  - **一個八度以內（7–12 個半音）**：共 **150 首（34.2%）**，其中剛好跨越**一個純八度（12 個半音）**的歌曲有 **115 首（26.2%）**。
  - **九度至十度（13–16 個半音）**：共 **202 首（46.0%）**，其中跨越**大九度（14 個半音）**的歌曲有 **146 首（33.3%）**，是最常見的音域寬度。
  - 合計有 **80.2%（352 首）** 的歌曲音域控制在十度（16 個半音）以內，符合學童自然歌唱的舒適音區。
- **各年級音域變化**：一年級與二年級平均音域約為 **13.1–13.2 個半音**，四年級至六年級微幅擴大至 **14.1–14.3 個半音**，到了包含二部合唱的高等科則約為 **14.2–14.8 個半音**。

## 附註

- **關於 TMD 格式**：本計畫使用 [TMD（Timebase Markdown / Textual Music Description）](https://tmdlang.github.io/) 作為底層的樂譜紀錄格式。TMD 是一種概念接近「純文字簡譜＋Markdown」的音樂記述語言，所有音符、節奏與和弦都以純文字檔案（`.tmd`）儲存，不僅容易閱讀與透過 Git 進行版本管理，也能隨時透過工具自動轉出成五線譜、MIDI 或音訊檔。
- **AI 辨識與轉換工具**：本專案之原書掃描影像樂譜辨識、日文歌詞轉錄、TMD 格式轉換以及雙手鋼琴伴奏編曲，係使用 **Google Antigravity / Gemini** 輔助完成。
