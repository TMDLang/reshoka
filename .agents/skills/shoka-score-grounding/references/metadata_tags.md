# Re:shōka `.tmd` Metadata 標籤與「歌曲來源系譜」分類規範

本文件定義 Re:shōka 專案所有歷史樂譜 `.tmd` 檔案標頭（`::SCORE::` 下方、`{` 之前）所使用的 `~ "tag: <key>:<value>"` 結構化標籤體系，作為全庫單一事實來源（SSOT）與各冊「專題統計」自動計算之依據。

---

## 一、基本書目與轉錄狀態標籤（單選為主，`source` 可複選）

每首歷史教材主旋律 `.tmd` 均應包含以下基礎標籤：

| 標籤鍵 (`<key>`) | 允許值 (`<value>`) | 說明 |
| :--- | :--- | :--- |
| `collection` | `kyoeki_shoka`, `taiwan_shuyu_shoka`, `kogakko_shokashu_1915`, `shoka_kyozai_shu_1923`, `shokacho`, `taiwan_no_uta`, `shintei_jido_shoka`, `kogakko_shoka`, `utanohon` | 所屬歌集代號 |
| `volume` | 如 `grade_1`, `grade_1_2`, `koto_1_2`, `vol_01` 等 | 所屬冊別／學年代號 |
| `source` | `school_textbook`（學校教材／歌集）、`shokacho_notebook`（楊金土手抄唱歌帖）、`horai_shokashu`（抄自《蓬萊唱歌集》） | 載體形式（若為《唱歌帖》中抄自《蓬萊唱歌集》之曲目，同時標註 `shokacho_notebook` 與 `horai_shokashu`） |
| `source_page` | 如 `P008`, `P125` | 對應掃描圖檔頁碼 |
| `provenance` | `printed_text`（印刷課本）、`manuscript_copy`（手抄本）、`printed_insertion`（手抄本夾頁印刷品）、`printed_sheet`（單張印刷譜） | 原件物理屬性 |
| `evidence` | `scan_verified`（已經高解析切片雙通道校對）、`editorial`（初步轉錄待複核） | 校對驗證狀態 |
| `version` | `source_transcription` | 版本性質 |
| `orthography` | `historical_kana` | 保留戰前歷史假名遣與舊字體 |

## 二、歌曲來源系譜標籤（`tag: origin:<value>`，支援多重來源複選）

日治時期臺灣校園傳唱的「唱歌」並非單一來源，而是由多條歷史曲庫交會而成。每一首 `.tmd` 必須至少標註一個 `~ "tag: origin:<value>"`；**當一首歌曲同時具備多重源流（例如「西洋民謠經明治文部省唱歌集收錄定型」或「總督府國語讀本新課文由臺籍教師譜曲」）時，應同時標註多個 `tag: origin:...`**。

## 三、多重來源（Multi-label `origin:`）標註原則

當一首歌曲在歷史傳播過程中橫跨兩個以上的曲庫系統時，應**並列多個 `tag: origin:...`**：

1. **西洋曲 × 文部省／明治教科書**：
   - 如〈卒業の歌（あふげば尊し）〉、〈螢の光〉、〈故郷の空〉、〈埴生の宿〉：同時標註 `origin:western_melody` 與 `origin:monbusho`（或 `origin:meiji_textbook`）。
   - 如《共益商社唱歌教科書》中的〈來れ遊べ〉、〈コロンブス〉：同時標註 `origin:western_melody` 與 `origin:meiji_textbook`。
2. **文部省／內地原曲 × 臺灣總督府在地改作**：
   - 如 1915《公學校唱歌集》與 1923《唱歌教材集》中的〈花〉（將文部省原詞「れんげの花」改為臺灣「佛桑花」）：同時標註 `origin:monbusho` 與 `origin:taiwan_official`。
3. **臺灣總督府國語讀本新課文 × 臺籍教師譜曲／內地出版社另譜**：
   - 如《蓬萊唱歌集》中由臺籍訓導郭水返為 1923 年《公學校用國語讀本》卷三課文譜曲的〈水グルマ〉（D 大調）：同時標註 `origin:taiwan_official` 與 `origin:taiwan_teacher`。
   - 如 1930《新定兒童唱歌》中為同一篇《公學校用國語讀本》課文另譜 F 大調新曲的〈水グルマ〉：同時標註 `origin:taiwan_official` 與 `origin:taisho_showa_mainland`。
4. **1933 年全島懸賞募集入選歌詞 × 1934 總督府官定《公學校唱歌》**：
   - 如〈カアレン〉、〈ユフダチ ヤンダ〉等 16 首編入《公學校唱歌》之懸賞入選曲：同時標註 `origin:taiwan_official` 與 `origin:taiwan_contest_1933`。
