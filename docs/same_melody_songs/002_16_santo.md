# 同曲異詞：三都／靖國神社

## 差異原因（推測）

這些版本可能來自不同歌集、抄本或教學場合；同一旋律在傳抄與教材編纂過程中被配上另一套歌詞。

## 判讀

各版本的旋律音級序列達到自動比對門檻，但歌詞正規化後仍分成不同版本。這裡的「同曲」是資料分析候選，不取代逐小節的人工校勘。
