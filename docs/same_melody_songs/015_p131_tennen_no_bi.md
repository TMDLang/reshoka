# 同曲異詞：天然の美／美しき天然

> 這是旋律相似度比對產生的待確認候選，仍應回看各版本原始掃描與樂譜確認。

## 差異原因（推測）

兩版本都歌詠自然聲響與景色，但文字不是逐句改寫，而是不同歌詞配在同一旋律上；曲名也從「天然の美」轉成「美しき天然」，反映流通版本的題名與填詞差異。

## 判讀

各版本的旋律音級序列達到自動比對門檻，但歌詞正規化後仍分成不同版本。這裡的「同曲」是資料分析候選，不取代逐小節的人工校勘。
