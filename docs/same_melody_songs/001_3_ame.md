# 同曲異詞：雨

> 這是旋律相似度比對產生的研究候選，仍應回看各版本原始掃描與樂譜確認。

## 版本比較

| 版本 | 年代 | 歌名 | 歌詞（正規化讀音） | 出現處 |
| :---: | :---: | :--- | :--- | :--- |
| 1 | 1900 | **雨** | `いずこおいでていずこにいたるあしぶみはやくまどうつあめよくもよりいでてくさばにやどるせはしやわれはきのふもきょうも` | **《共益商社唱歌教科書》卷二・教師用（明治33年／1900）**：[〈雨〉](kyoeki_shoka/kan_2_854863/3_ame/index.md) |
| 2 | 1923 | **雨** | `いずこおいでのいずこにいたるあしぶみはやくまどうつあめよ` | **楊金土手抄《唱歌帖》第 3 冊・I（2020.006.0843）**：[〈雨〉](shokacho/vol_03/p036_ame/index.md) |

## 差異原因（推測）

兩個版本保留相同的雨景與行進意象，但楊金土本的句子較短、部分語句不同，較像從另一歌集或手抄流傳本節錄，而不是單純男女教材改詞。

## 判讀

各版本的旋律音級序列達到自動比對門檻，但歌詞正規化後仍分成不同版本。這裡的「同曲」是資料分析候選，不取代逐小節的人工校勘。
