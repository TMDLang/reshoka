# 同曲異詞：送別の歌／螢の光／告別

> 這是旋律相似度比對產生的待確認候選，仍應回看各版本原始掃描與樂譜確認。

## 差異原因（推測）

三個版本都使用送別旋律，但歌詞分別採用不同的畢業、惜別與《螢之光》文本；這是同一旋律跨文化、跨教材重新填詞的典型例子。

## 判讀

各版本的旋律音級序列達到自動比對門檻，但歌詞正規化後仍分成不同版本。這裡的「同曲」是資料分析候選，不取代逐小節的人工校勘。
