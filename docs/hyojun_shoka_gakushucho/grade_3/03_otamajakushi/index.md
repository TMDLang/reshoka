## 歌詞

```text
一、
お玉じやくしは　眞黑で、
頭がまるく　尾が長く、
手足はなくても　ちよろ／＼と、
池の中をば　かきまはる。
お玉じやくしは　かわいいな。

二、
お玉じやくしの　尾がとれて、
蛙となつて　手が出きて、
あーしが出きては　ぴよん／＼と、
草の中をば　とびまはる。
蛙のこどもは　かわいいな。
```
