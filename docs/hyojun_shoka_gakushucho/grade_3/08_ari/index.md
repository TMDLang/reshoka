## 歌詞

```text
一、
みんな手をかせ　えんやらや。
重いぞいも蟲　えんやらや。
さあ／＼ならんで　みんなこい。
來たらいも蟲　ひつかけ。

二、
大きなとび石　水たまり、
つらい道でも　がまんして、
引いたぞ穴まで　えんやらや。
それもう　ちきだぞ引いて行け。
```
