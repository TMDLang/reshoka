## 歌詞

```text
一、
ねんねのお里のげんげ草、
ぽちぽち牛もあそんでる。
牧場の牧場のげんげ草、
誰かごほくでよんでゐる。

二、
ねんねのお里はよい田舎、
ねんねのお汽車で、下りたなら、
道はひごすら、たんぼ道、
わらやに緋桃も咲いてゐる。

三、
ねんねのお守はゐやせぬか。
ちよろちよろ小川もながれてる。
いつだか見たよな橋もある。
小藪のかげにはえんまだう。

四、
ねんねのお里で泣かされて、
おせごにでてみたげんげ草、
あああの紅いげんげ草、
誰か遠くで呼んでゐる。
```
