## 歌詞

```text
一、
ゆらり／＼と　波間の船の、
竿の先なる　扇の的よ。
遠くはなれて　其の的ねらふ。
那須與一は　弓矢の選手。

二、
ゆたり／＼と　乗り出す馬の、
波に浮びし　其のひと時よ。
ねらひ定めて　はなしし一矢。
浦に響きて　飛び行くうなり。

三、
ひらり／＼と　夕日に舞ひて。
波の上へと　扇は落つる。
よくも要を　射切りにけりな。
那須與一は　弓矢の選手。

四、
射たり／＼と　味方も敵も。
鞍をたたきて　ふなばたたき、
陸と海とに　どよめきたりな。
弓矢とる身の　上なき譽。
```
