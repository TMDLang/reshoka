## 歌詞

```text
一、
縄手伝ひに来る風も、
若葉の匂ひかんばしく、
空一ぱいの星は皆、
すずしく金にまたたくよ。

二、
田面は水のひろびろと、
蛙の聲も　にぎはしく、
谷あひの家　窓あけて
夜に親しむ　時は來ぬ。
```
