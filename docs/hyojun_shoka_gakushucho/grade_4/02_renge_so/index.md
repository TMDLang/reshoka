## 歌詞

```text
一、
今はれんげの　花盛り
田にも畑にも　一面に
花もうせんを　敷きつめて
紅や紫　うつくしい。
ああれんげさう　れんげさう

二、
手にも籠にも　摘みためて
楽しい心　もろともに
春の御神に　ささげませう。
```
