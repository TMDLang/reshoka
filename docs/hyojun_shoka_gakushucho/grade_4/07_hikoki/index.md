## 歌詞

```text
一、
何の音ぞ　何の響ぞ、
耳をうばふ　あやしの音や。
あれ　あれ　今し見上ぐる空を、
日影をかすめて　鵬翼はり、
飛行機とびゆく　いさましく。

二、
見やる間に　空をよこぎる、
力づよき　鵬翼や。
あれ　あれ　もはや彼方のはての、
雲間を縫ひつつ　小鳥のごと、
飛行機消えゆく　かすけくも。
```
