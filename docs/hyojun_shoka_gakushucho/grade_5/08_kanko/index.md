## 歌詞

```text
一、
日かげ遮（さへぎ）るむら雲に、
干すよしも無き濡衣を
身には著つれど、眞心の
あらはれずして止まめやと、
神のまもりをたのみつつ
配所に行きし君あはれ。

二、
のちを契りし梅が枝に、
東風吹く春はかへれども、
菊の節會の後朝の
宴に侍りし秋は來ず、
御衣を日毎に拜しつつ、
配所に果てし君あはれ。
```
