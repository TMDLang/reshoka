# 書訊與卷首／卷末掃描頁 — 《尋常小學唱歌》 第五學年用（廣島大學圖書館 ID 4100，大正2年／1913）

本頁收錄本冊之封面、扉頁、目次（もくろく）、樂典大要、版權頁與封底等原書掃描圖檔（共 5 頁）。

### P001.jpg

本冊封面（右頁），題「尋常小學唱歌　第五學年用　文部省」。

![《尋常小學唱歌》 第五學年用（廣島大學圖書館 ID 4100，大正2年／1913） 原書掃描頁 P001.jpg](P001.jpg)

### P002.jpg

目次頁（「もくろく」）：列出卷首「みがかずば」、「金剛石　水は器」及「一　八岐の大蛇」至「十九　卒業生を送る歌」共 21 首曲名與頁碼。

![《尋常小學唱歌》 第五學年用（廣島大學圖書館 ID 4100，大正2年／1913） 原書掃描頁 P002.jpg](P002.jpg)

### P003.jpg

卷首儀式歌〈君が代〉、〈勅語奉答〉、〈一月一日〉、〈紀元節〉、〈天長節〉歌詞與五線譜對照。

![《尋常小學唱歌》 第五學年用（廣島大學圖書館 ID 4100，大正2年／1913） 原書掃描頁 P003.jpg](P003.jpg)
