# 《尋常小學唱歌》 第一學年用（廣島大學圖書館 ID 4103，明治44年／1911）

> 日本文部省於明治 44 年至大正 3 年（1911–1914）編纂發行之第一套國定五線譜唱歌教科書《尋常小學唱歌》（全六冊，共 120 首），不僅奠定近代日本童謠與學校唱歌之核心曲目（如〈日の丸の旗〉、〈鳩〉、〈かたつむり〉、〈桃太郎〉、〈春が來た〉、〈茶摘〉、〈汽車〉、〈蟲の聲〉、〈村祭〉、〈春の小川〉、〈村の鍛冶屋〉、〈海〉、〈冬景色〉、〈朧月夜〉、〈我は海の子〉、〈故郷〉等），更直接成為臺灣總督府《公學校唱歌集》（1915）、《新編小學校・公學校唱歌教材集》（1923）、《新定兒童唱歌》（1930）與《公學校唱歌》（1934–1942）最重要的母本來源。掃描影像取自廣島大學圖書館數位典藏「近代の教科書」（公開資料）。（[廣島大學圖書館 ID `4103`](https://dc.lib.hiroshima-u.ac.jp/text/metadata/4103)）
