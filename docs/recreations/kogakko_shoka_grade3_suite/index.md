# 《公學校唱歌》第三學年室內樂組曲

這是一套以日治時期臺灣總督府編纂的《公學校唱歌》第三學年教材為素材，重新創作而成的室內樂組曲。作品保留原曲的旋律輪廓與歷史聲響記憶，將五首短篇唱歌串連成一個具有序奏、過場、調性轉換與終曲的完整音樂旅程。

本組曲不是原始史料的復原，而是以歷史曲目為出發點的再創作：木管樂器輪流承擔歌唱性旋律，弦樂補足長線條與內聲部，鋼琴則連結節奏、和聲與場景轉換。

## 曲目與結構

1. 序奏：雨後山嵐・晨光初綻
2. 第一樂章：〈あをば〉（青葉）— Andantino Pastorale
3. 過場一：山林軌道・台車啟動
4. 第二樂章：〈だいしゃ〉（台車）— Allegretto Giocoso
5. 過場二：村口鐵店・火星飛濺
6. 第三樂章：〈村のかじや〉（村之鍛冶屋）— Allegro Scherzando
7. 過場三：鐵鎚遠去・烈日白道
8. 第四樂章：〈牛車〉— Andante Espressivo
9. 過場四：夕陽歸途・迎向長假
10. 第五樂章：〈ながいお休〉（長假）— Allegro Moderato e Festoso
11. 終曲：公學校四季回憶・主題交織大合奏

全曲以 D 大調為起點，依序經過 F 大調、G 大調與 E 大調，最後回到 D 大調。調性拱形與五首歌曲的主題順序，構成從晨光、勞動、村落、歸途到假期的敘事弧線。

## 編制

室內樂六重奏：

- 長笛
- 雙簧管
- 單簧管
- 小提琴
- 大提琴
- 鋼琴
