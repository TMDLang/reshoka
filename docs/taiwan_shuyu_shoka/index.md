# 《臺灣周遊唱歌》 明治四十三年初版／大正元年八版（國臺圖 0786 10）

> 國立臺灣圖書館「日治時期圖書影像系統」典藏號 **`jpli2011-bk-sxt_0786_10_1912`**（索書號 **`0786 10`**，杉浦和作舊藏寄贈）。明治 43 年（1910 年）2 月 20 日初版、大正元年（1912 年）12 月 18 日八版，**宇井英**作歌、**高橋二三四**作曲，臺北**新高堂書店**（村崎長昶）發行。全曲採七五調 **90 節**長篇地理唱歌形式，配合 1908 年全線通車之臺灣縱貫鐵路與東岸環島航線，自基隆港出發環遊全臺名勝古蹟與物產；樂譜為 F 大調（ヘ調）2/4 拍、五線譜與數字簡譜上下並列。本資料庫同時提供**簡單版（譜面第 1～4 節對位＋全 90 節歌詞檢索）**與**完整版（全 90 節歌詞完整對位與超長版合成音訊）**兩種版本。
