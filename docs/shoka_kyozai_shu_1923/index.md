# 《新編 小學校・公學校 唱歌教材集》（大正十二年／1923）

《新編 小學校・公學校 唱歌教材集》由時任臺灣總督府編修官、臺北第一師範學校教諭兼訓導的**一條慎三郎**編纂，於**大正十二年（1923）12 月**由**臺北杉田書店**發行。

本教材集是 1922 年《新臺灣教育令》公布、「日臺共學」學制改革後，臺灣初等教育領域最早嘗試全面統合小學校與公學校教學進度的大型音樂教材集之一。全套涵蓋尋常科一至六年級與高等科一、二年級，整理為四個卷冊，合計收錄 **201 首曲目**。

## 歷史物質條件：3 圓 50 錢的定價與教師手抄時代

1. **新教育令下的教材統合嘗試**：
   1922 年總督府頒布《新臺灣教育令》，標榜「日臺共學」與小學校、公學校修業年限及課程標準銜接。在此背景下，一條慎三郎廣泛納入日本文部省國定唱歌、公學校用國語讀本配歌、明治民間檢定唱歌與西洋古典合唱曲，建構出一套從初小遊戲兒歌至高小二部合唱、輪唱的階梯式教材。
2. **3 圓 50 錢的昂貴身價與「學校教席公用本」**：
   在 1920 年代初期，**3 圓 50 錢**是一筆極為可觀的開銷。根據中央研究院臺灣史研究所《[臺灣總督府職員錄系統](https://who.ith.sinica.edu.tw/)》，當時剛從師範公學畢業任教的臺籍初任教員（訓導心得、准訓導、代用教員），每月月俸僅約 **20～25 圓**（且無日籍教師外加 60% 之加俸津貼）。一本 3 圓 50 錢的教材集，相當於年輕教員半個月薪資的 **15%～18%**。一般公學校學童家庭根本無力自購，因此本書主要由公學校以公費採購一套，置於音樂教室或教員室作為全校教師備課共用的「教席公用參考書」。
3. **催生「5 錢、9 錢筆記本」的手抄文化**：
   由於昂貴原版歌本無法普及至個人，公學校基層教師為了進班授課，紛紛自行購買大阪／東京「株式會社文運堂」印製、一本僅 **5 錢**（如臺史博館藏 [`2020.006.0841`](https://collections.nmth.gov.tw/CollectionContent.aspx?a=132&rno=2020.006.0841)）或 **9 錢**（如 [`2020.006.0842`](https://collections.nmth.gov.tw/CollectionContent.aspx?a=132&rno=2020.006.0842)）的空白五線譜《唱歌帖》。利用課餘借閱公用書之際，手工將全曲旋律抄錄下來，甚至在符頭上方註記簡譜以利風琴伴奏。老松公學校教員楊金土的手抄本中，即有高達 **53 首曲目** 與本書完全重合，第 10 冊抄錄〈夜の歸雁〉時更保留了「423頁」的對應原書頁碼，生動見證了「3 圓 50 錢昂貴原書」催生臺灣基層教師「5 錢手抄本」的物質文化史。
