```text
【原書第 24 頁日文解說原文】
トイソ 解説
勇壯なる曲の趣から推して、戰鬪或は、出草（首狩りの事）に、關係のある歌だと思はれるが、古語で、意味不明。だが、半分以上は感嘆詞であらうと、考へられる。

【客觀繁體中文語譯】
從這首曲子雄壯的曲趣推測，似乎是與戰鬥或出草（獵首）相關的歌曲，但因屬古語，詞意不明。不過推測其中半數以上應為感嘆詞。
```
