## 歌詞

```text
サキヨ　カラロー
オー　ウミタカ
クアナ

【原書解説原文（P004：サキヨ解説）】
「サキヨ」と言ふ曲の名は、歌詞の最初の一句をとつたものである。
こんな例は澤山ある。蕃人の歌だけではなく、日本の「春雨」「槍さび」西洋の「アベ・マリヤ」「レクキェム」等も、矢張り此の式である。
古語であつて、歌詞の意味は不明。蕃人のだれもが最も好んで、しばしば唱ふものゝ一つである。

【原書解説中譯】
「サキヨ」這個曲名取自歌詞最初的一句。
這樣的例子非常多。不僅止於原住民的歌曲，日本的《春雨》、《槍さび》，以及西洋的《聖母頌》（Ave Maria）、《安魂曲》（Requiem）等，也同樣採用此種命名方式。
歌詞為古語，其含義不明。此曲為原住民人人最為喜愛、並經常詠唱的歌曲之一。
```
