## 序言釋讀與語譯

### 原書序文（竹中重雄）

> **序**  
> 此歌集に收められた、台灣蕃族の十二曲は、私が台灣在職中、番地に出入して、彼等と生活を共にしながら、記錄したものである。  
> 月の美しい夜、檳榔の葉蔭に蕃人と共に手を攜へて踴り、或時は又、番屋に焚火を圍んで酒を酌みかはした事もあった。  
> 其時々に聞いた、蕃人達の歌に、限りなく豊かな藝術味を感じ、何とかしてこれらの旋律を記錄に殘しておきたいと思ひ、機會ある毎に、書き留めておいたものが、今では數十曲に及んでゐる。其中、この十二曲をまづ刊行して、斯道諸兄姉の御批判を仰ぐ事にした。  
> これらの歌は、現在台灣に住んでゐる蕃族七種族（タイヤル族、サイセット族、ブヌン族、ツウオ族、パイワン族、アミ族、ヤミ族）の中、新高山の西、主として阿里山方面に住んで居る、ツウオ族のものである。ツウオ族は人口約二千、古くから首狩りの惡習を斷ち、今では我が官憲の保護の下に、平和な生活を樂しんで居る。  
> 旋律の記錄に際しては、速度をメトロノームで、高度を音叉又は調子笛で決定した。又番人達は、同じ歌を唱つても、みんなどこか少しづつ違ひ方をするので、一つの歌の記錄にも、少くとも數人の番人に唱はせてみて、其各々の記錄から、私が編曲したものである。旋律だけでは、やや單調に失すると思つたので、簡單なピアノ伴奏を附けておいた。何よりも殘念なのは、歌詞の意味の、不明なのが多い點であるが、これは私自身、此の方面の知識に缺けてゐるのと、公職を持つかたはらの調査であつたため、時日も十分でなかつた等から、こんな結果になつてしまつたのである。將來此方面にも大いに勉強して、この記錄の完成を期したいと思つてゐる。  
> 續いて第二、第三、第四集をも刊行する積りでゐる。  
> 
> 昭和十年八月  
> **竹 中 重 雄**

### 序文中譯

收錄於本歌集中的臺灣原住民歌謠十二首，是我在臺灣任職期間出入蕃地，與他們共同生活時所記錄下來的成果。  
在明月高照的夜晚，於檳榔樹蔭下與原住民攜手共舞；或圍繞著家屋中的篝火暢飲共酌。在那些時刻所聽見的原住民歌聲，讓我感受到無限豐富的藝術韻味，總想著無論如何都要將這些旋律以文字與符號記錄下來。每逢機會便隨手記下，至今累積已達數十曲。此次先將其中十二首整理出版，藉此向音樂界前輩與同道請教指正。  
這些歌謠屬於現今居住於臺灣的七個原住民族（泰雅族、賽夏族、布農族、鄒族、排灣族、阿美族、雅美族）之中，分佈於新高山（玉山）以西、主要居住於阿里山一帶的鄒族（ツウオ族）。鄒族人口約兩千人，早年便斷絕了獵首惡習，如今在官方的保護與治理下安居樂業。  
在記錄旋律時，拍速以節拍器（M.M.）測定，音高則以音叉或調子笛精準確定。又因族人即使演唱同一首歌，各人唱法亦往往略有差異，因此每首歌的採集都至少請數名族人反覆演唱，綜合各次記錄後由我整理編曲。為免單旋律過於單調，特為每曲編配了簡易的鋼琴伴奏。最為遺憾的是多數歌詞意義未能完全明瞭，這由於我自身在此領域語言知識尚有不足，且係利用公職之餘展開調查、時間未能充裕所致。未來定當在此方面多加鑽研，以期這項記錄更臻完整。  
後續亦計劃陸續發行第二、第三、第四集。  
昭和十年八月  
**竹中重雄**
