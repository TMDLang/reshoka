## 歌詞

```text
タグガテ　パタランタ
マエ　チエチエ
マエカナ　ナヲマ

【原書解説原文（P002：パタラン解説）】
大昔の歌である。作られた當時には。恐らく、歌詞にも、曲にも、判然とした意味を有つて居たのであらうと思はれるが、今では一体どんな意味を有つた歌詞であるか、又どんな場合に唱はれた歌であるかゞ、全く分らなくなつて仕舞つてゐる。
蕃人の歌には、この種のものが、かなり多い。

【原書解説中譯】
這是一首極為古老的歌。在創作當時，無論歌詞或曲調恐怕都曾具有明確的含義，然而到了今日，歌詞究竟帶有什麼意義、又是在何種場合下詠唱的歌曲，都已經完全無從得知了。
原住民的歌曲中，屬於這一類的作品相當多。
```
