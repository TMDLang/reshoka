調性與拍號：ヘ調（F 大調，一降記號）四分の四拍子（C / 4/4）

採集地點：臺灣阿里山鄒族（ツウオ族）


## 歌詞

```text
チヨコノヤ ユフチヨヤ
ヌホーラ
ウタイヤアウ
マオニヤ
マウワマウ

【原書解說（第16頁「パスフムチヨイ解説」原文照錄）】
パス、フムチヨイは死の悲しみを歌つたものである。
自分の兩親は死んでしまつたが、自分にはどうしても、生きて居るとしか思へず、日夜兩親の事ばかしを考へてゐるものだから、泣けて、目がこんなに腫れて仕舞つた。と言ふ意味を有つてゐる。
人種の如何を問はず、親に對する、子の思ひの切なるものには、變りがないものと見へる。

【解說中譯】
「パス フム チョイ」是歌唱死亡之悲傷的歌曲。
其意涵為：「自己的雙親雖然已經過世，但自己無論如何都只覺得他們還活著，因為日夜只思念著雙親的事，忍不住哭泣，眼睛才腫成這個樣子。」
不論種族為何，子女對雙親真摯深切之思念，似乎並無二致。
```
