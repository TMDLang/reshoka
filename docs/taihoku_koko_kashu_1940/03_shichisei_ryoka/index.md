## 歌詞

```text
一、
陽炎燃ゆる南津國　旭日高く東洋の
平和の空を朱に染めし　見よ新高の朝の色
破邪の弓矢背に負ひて　獨立自尊の劍を執り
亂魔の天地驅けめぐる　見よ七星の健男兒

二、
朝南溟に霧晴れて　綠滴る橄欖の
馥郁の香にそゝられて　希望の花を翳しつゝ
身は青春の血に燃えて　感激溢れし若人よ
眞の步選ばせて　南の空に雄飛せむ

三、
人高樓の夢に醉ひ　玉殿深き歡樂の
宴に夢を結ぶとき　見よ東の空晴れて
清廉の氣は嚴かに　自由正義の火を點ず
見よ國南の健男兒　聽け七星の雄叫びを

四、
世は桃源の春深く　人は惰眠に耽る時
彩雲映ゆる曙に　大鵬雲に羽搏きて
忽ち騰る十萬里　地軸をゆする轟々の
自治の男子の肉躍る　七星寮の健男子
```
