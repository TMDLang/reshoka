## 歌詞

```text
一
げんぺいしようぶの　はれのばしよ
ぶうんはこの矢にさだまると
なすのよ一は一しんふらん
ねらひさだめて　ひようといる

二
あふぎは夕日にきらめきて
ひら／＼落ちゆく波の上
なすのよ一のほまれは今も
屋島のうらに　なりひびく
```
