```text
こちらへおとほりあそばせな
私の大事なお人形が
かげんがわるくて昨日から
ちつともゑがほを見せませぬ』

おねつがたくさんありますか』

お手々もお足もつめたくて

何にも食べずにねてゐます
ほんとにどうしたことでせう』
```
