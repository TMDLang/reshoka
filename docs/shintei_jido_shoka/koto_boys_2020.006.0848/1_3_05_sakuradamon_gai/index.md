## 歌詞

```text
一
櫻田門外の、
雪を侵して進みし、
大丈夫十八士、
つひに掃部を刺しぬ。
氷なせる刃、
櫻よりも赤き血潮、
見よや世々に殘す、
維新歷史の形見。

二
我が首斬らるとも、
いかで變ふべき我が説。
男子の執るところ、
堅き巖の如し。
縱や其身春の、
雪と共に消えぬとても、
消えず朽ちぬ名こそ、
世々を照らす光。
```
