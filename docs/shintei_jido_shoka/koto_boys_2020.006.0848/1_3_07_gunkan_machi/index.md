## 歌詞

```text
一
守るも攻むるも鋼鐵の
浮べる城ぞ頼みなる
浮べるその城日の本の
皇國の四方を守るべし
まかねの其艦日の本に
仇なす國を攻めよかし

二
石炭の烟は渡津海の
龍かとばかり靡くなり
彈丸打つひびきは雷の
聲かとばかりどよむなり
萬里の波濤を乗り越えて
御國の光　輝かせ
```
