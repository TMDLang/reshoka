## 歌詞

```text
一　この世に生れて空しく果てんや
鐵石の腸（はらわた）われにあり
苦しみ來（こ）よ憂き事來（こ）よ
日頃の覺悟をいざや示さん
これこそわれらの守れる主義なれ
これこそわれらのねがひなれ

二　曇（くも）らぬ心に充ちたる勢力（ちから）は
山をもゆるがす强さあり
これを賴みこれに憑（たよ）り
いのちの限りをわれは振はん
これこそわれらの守れる主義なれ
これこそわれらのねがひなれ
```
