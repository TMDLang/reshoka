```text
長閑（のど）けき春（はる）を、知（し）らぬ顏（かほ）に、
一筋道（ひとすぢみち）を、駈（か）けて行（ゆ）く。

二　一望（いちばう）千畝（せんぽ）、麥（むぎ）は秀（ひい）で、
春草（しゅんさう）萌（も）ゆる、田舍道（ゐなかみち）。
郵便車（いうびんぐるま）、日毎（ひごと）に引（ひ）きて、
通（かよ）ふは誰（た）が子（こ）、誰（たれ）の爲（ため）に、
長閑（のど）けき春（はる）を、よそにして。
```
