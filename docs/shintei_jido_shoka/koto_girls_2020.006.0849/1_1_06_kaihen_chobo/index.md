```text
眺（なが）むる心（こころ）も高く廣し
うれしきながめや遠（をち）のうなばら
たのしきながめや遠のうなばら

二
のどかにひゞく浪（なみ）のしらべ
うれしげになく千鳥（ちどり）のこゑ
わが大君（おほぎみ）を八千代（やちよ）ませと
いづれか祝（いは）はぬ浪も鳥も
うれしきしらべや浪のひゞきは
たのしきしらべやうたふ千鳥は
```
