```text
一
空やおほへる廣き水を
水やひたせる高き空を
ひとつになれる海と空と
眺むる心も高く廣し
うれしきながめや遠のうなばら
たのしきながめや遠のうなばら

二
のどかにひゞく浪のしらべ
うれしげになく千鳥のこゑ
わが　大君を八千代ませと
いづれか祝はぬ浪も鳥も
うれしきしらべや浪のひゞきは
たのしきしらべやうたふ千鳥は
```
