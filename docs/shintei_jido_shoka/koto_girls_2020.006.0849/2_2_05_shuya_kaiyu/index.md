```text
吾のみひとり淋しき窓に
變らぬ月を眺めぞあかす

端居（はしゐ）の夕べ手をとりかはし

誓ひしものを其友今は
海山遠き彼方の里に
なきゆく雁をいかにかきける
み空の月よ俤（おもかげ）うつせ
```
