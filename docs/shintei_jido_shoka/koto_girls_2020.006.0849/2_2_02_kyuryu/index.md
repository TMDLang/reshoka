```text
雷の響は　巖を打つ
愉快に躍り　愉快に舞踏して
いつまでも飽かず　遊べや遊べや

二
矢を射るに似て　早き流れ
鋒（ほこさき）を揃へて　落ちくる瀧つ瀨
膽（きも）も冷えて　夏さむく
まろび散る白玉　皷（つゞみ）の聲
嬉しく歌ひ　楽しく唱歌して
足ぶみも高く　遊べや遊べや
```
