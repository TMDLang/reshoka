```text
一

紅葉も花もまだしらぬ　世にさきがけの名も高き
梅は月の瀨月雪の　外にひとつの見どころぞ

二
雪げの水もきのふけふ　歌ごゑたつる名張川（なばりがは）
かなたこなたに枝かはす　千本（ちもと）の梅の花みれば
星の林か白雲か　かをりぞ空に滿ちわたる

三
村より村にさきつゞく　梅より梅の夕月夜
おもひぞ出づる春毎に　心かなたにゆきかひて
かすむか今も麗はしく　伊賀と大和の山かげに
```
