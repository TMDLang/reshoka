## 歌詞

```text
一
人里離れし山路の伏屋
病みたる母をば救はんものと
少女のまごころ醫師のもとに
深雪を分け行く姿おぼろ

二
吹く風もり來る網代（あじろ）の屏風
細りし寢顔をつくづくまもり
をとめの眞心ほとけのもとに
惠みを祈れる腕（かひな）痩せぬ
```
