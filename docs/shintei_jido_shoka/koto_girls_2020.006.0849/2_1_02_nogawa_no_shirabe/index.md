## 歌詞

```text
一、
野川の水のさゝやきに
春を喜ぶ調べあり
水（み）の面（も）に浮ぶ花びらは
音なく靜（しづ）かに流れ行く

二、
花の行へは遠けれど
川の調べにつれられて
岸邊の草とかたらひつ
音なく靜かに流れゆく
```
