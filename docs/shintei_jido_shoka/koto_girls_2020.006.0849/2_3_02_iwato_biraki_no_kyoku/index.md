```text

山より谷へと　應（こた）へて響きぬ

二
中にもやさしき　鈿女（うづめ）の命は
正木の若葉を　鬘（かづら）に戴き
日蔭のかづらを　襷（たすき）にあやどり
覆槽（うけ）ふむ足どり　とどろの足音

三
神々華（はな）々　ゑらぎて笑へば
岩戸を細目（ほそめ）に　何事ならんと
大神少しく　覗（のぞ）かせ給ふ
すかさず驅（か）けよる　剛氣の手力（たちから）

四
岩戸は放れて　天照（あまて）る御光（みひかり）
闇路（やみぢ）に開きし　瞳（ひとみ）はまばゆく
面（おも）々眞白（ましろ）に　面白面白
めでたしめでたし　世は又晝とぞ
```
