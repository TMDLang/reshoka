# 《臺灣教育》第 334 號〈新定兒童唱歌〉出版介紹與公認史料考證

本頁收錄昭和五年（1930年）5月1日由財團法人臺灣教育會發行之機關刊物**《臺灣教育》第 334 號**第 152 頁刊登之**〈新定兒童唱歌〉**新書出版介紹完整原文翻刻、中文語譯與出版史料考證。

這份文獻是日治時期臺灣教育會正式公認並推廣《新定兒童唱歌》全套教材的**核心原始官報文獻（Primary Source）**，不僅證實了全套教材自「尋常科一年級至高等科二年級」以**「小學校、公學校併用」**為明確編纂目的，更詳細揭露了日本現代教育唱歌作曲大家的選曲委員會、臺灣在地教材的編排特色、首創之新式假名譜與筆記五線紙，以及大阪「日本唱歌出版」與臺北、臺中、臺南各大總經銷書店的發行網絡。

```text
新定兒童唱歌

近來教育的に考へられない民謠や俗謠の出版流行につ
れ、學校の唱歌もそれらの影響を受け健全ならざる教材を
課する傾の現れは、國民教育上大に憂慮すべき點があるこ
いふ事に鑑み、東京大阪日本教育唱歌研究會では、我邦現
代教育唱歌作曲大家の作に係るもの、及び古來の歌曲で教
育的にも藝術的にも價値ある適切な材料を會議選擇し、各
府縣により其の地方に特殊なる鄉土的關係材料を考慮按配
し、唱歌教授上の改善を企圖するといふ目的で小學校各學
年に適當なる歌曲集を編纂する事になり、既に內地では各
府縣教育會で統一的に編纂し、又は音樂研究會等の協力會
議を経て夫に使用する事になつたといふ事は我邦初等教育
上時宜に適した企て、誠に喜ばしき事である、本島用の分
は新定國語讀本中の題文歌曲其の他本島に適切なる教材を
按配し、一年より高等二年まで各册公學校併用の目的で
兒童唱歌と題命し、臺灣教育會の公認を経たもので、一年
から三年迄は本譜の下に新式假名譜を附し三年以上は小公
學校に必要なる樂理の一班、發音口形圖、終りに筆記用五線
紙をつけ各學年約四十曲カット挿圖入表紙も兒童向上品に
出來て居て誠に初等教育唱歌教授上の福音といふべきであ
る發行は大阪日本唱歌出版 本島大賣捌所は 臺北 新高堂
文明堂、小供世界社 臺中 棚橋書店 臺南 小出書店である
```

## 四、現代繁體中文完整語譯

> ### 新定兒童唱歌
> 
> 近年來，隨著毫無教育考量的民謠與俗謠出版盛行，學校唱歌教育亦受到波及，出現了採用不健全教材的傾向。鑑於此一現象在國民教育上實屬極令人憂慮之處，**東京、大阪「日本教育唱歌研究會」**遂召集會議，自**我國現代教育唱歌作曲名家**的作品，以及古來流傳、兼具教育與藝術價值之歌曲中，嚴選適當教材；同時考量並調配各府縣特殊之鄉土教材，以改善唱歌教學為宗旨，著手編纂適合小學校各學年的歌曲集。目前在內地（日本本土），已由各府縣教育會統籌編纂，或經由音樂研究會等通力合作會議議定後正式採用，此舉實為切合我國初等教育時宜的創舉，誠屬可喜可賀之事。
> 
> **本島（臺灣）專用之版本**，則特別配合《新定國語讀本》中之課文題目歌曲與其他切合本島之教材進行調整按配，**自一年級至高等科二年級各冊，均以小學校、公學校併用為目的，命名為《兒童唱歌》，並業經臺灣教育會正式公認審定**。
> 
> 在教材編排上，**一年級至三年級於五線譜（本譜）下方特別附註「新式假名譜」**；**三年級以上則收錄小公學校必備之簡易樂理大綱、發音口形圖，每冊卷末更附設筆記用五線紙**。各學年均收錄約四十首曲目，配有精美插圖（Cut），封面裝幀亦呈現兒童向上之高雅品質，堪稱初等教育唱歌教學上的極大福音。
> 
> 本書之**發行出版者為大阪「日本唱歌出版」**；**本島總經銷處（大賣捌所）**為：
> 
> * **臺北**：新高堂、文明堂、小供世界社（子供世界社）
> * **臺中**：棚橋書店
> * **臺南**：小出書店

## 五、重大歷史考證價值解析

這篇刊載於 1930 年 5 月《臺灣教育》第 334 號的新刊推介，解決了長年以來臺灣音樂史與教科書制度研究上的多項懸案：

### 1. 釐清《新定兒童唱歌》正式公布與普及臺灣之精確年代（1930年5月）
國立臺灣歷史博物館典藏的這套楊金土舊藏本（館藏號 `2020.006.0847.0001`～`0849`），因歷經長年教學翻閱，其卷末版權頁墨跡多已淡化或磨損，過去學界多依改訂再版印記推估為昭和七至九年（1932–1934）。本篇官報文獻於**昭和五年（1930年）5月1日**正式刊出，確立了《新定兒童唱歌》在臺灣經過臺灣教育會公認審定、全面推向全島學校教育體系的**精準起始時間為 1930 年春季新學年**。

### 2. 首見「小學校・公學校併用」之官方明確定位
日治時期臺灣教育體制長期存在日人學童就讀的「小學校」與臺籍學童就讀的「公學校」雙軌制度。本報導明白揭示：
> **「一年より高等二年まで各册公學校併用の目的で兒童唱歌と題命し、臺灣教育會の公認を経たもの」**

這項記載證明《新定兒童唱歌》並非僅供內地人小學校使用的內地引進課本，而是**半官方的「臺灣教育會」為了縮小島內雙軌教育落差、特意調配臺灣在地課文後「小公學校共同適用」的統一標準唱歌教材**。全書不僅收錄日本內地名家新童謠，更積極收入描寫臺灣風土之課文歌曲（如〈高砂〉、〈淡水河〉、〈カーレンサン（花蓮港）〉、〈ガランビ（鵝鑾鼻）〉、〈芭蕉〉等），體現了 1930 年代初臺灣音樂教育「鄉土化」與「現代化」的折衷實踐。

### 3. 解密教學法上的「新式假名譜」與「筆記用五線紙」
報導詳實記錄了課本的版面設計原則：
* **「一年から三年迄は本譜の下に新式假名譜を附し」**：一至三年級的樂譜在正規五線譜下方，特別印刷了「ド、レ、ミ」新式假名唱名，讓初學日語與五線譜的低年級學童能夠「看詞即唱、看音即讀」，大幅降低臺灣公學校學童識讀西洋五線譜的門檻。
* **「三年以上は小公學校に必要なる樂理の一班、發音口形圖、終りに筆記用五線紙をつけ」**：中高年級課本不再只是歌曲集，更是一本兼具樂理講義、標準日語口型矯治（發音口形圖）與實作練習（書後空白五線譜練習紙）的整合式音樂教科書。

### 4. 首次完整還原全島出版與圖書發行經銷網絡
本篇文獻清楚揭露了《新定兒童唱歌》幕後的產銷鏈：
* **出版原產地**：**大阪「日本唱歌出版」**（由「東京大阪日本教育唱歌研究會」主編）。
* **全臺大賣捌所（總經銷商）**：
  * **臺北**：新高堂書店（本島最大書店）、文明堂書店、小供世界社（子供世界社，知名兒童教育出版社與雜誌社）。
  * **臺中**：棚橋書店（臺中州主要日文書肆）。
  * **臺南**：小出書店（臺南州知名老牌書店）。
  
這份經銷商名單生動勾勒出 1930 年代日治臺灣圖書流通重鎮的地理版圖，印證了全套教科書是如何透過遍布南北的各大書肆網絡，迅速分發到楊金土訓導等基層公學校教員與千千萬萬學童手中。
