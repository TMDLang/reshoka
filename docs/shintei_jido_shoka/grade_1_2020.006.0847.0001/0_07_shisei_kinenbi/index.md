```text
始（はじ）めて茲（こゝ）に敷きましゝ
よき日（ひ）を祝（いは）へ萬歳（ばんざい）に。

二　内外（うちと）の海（うみ）の隔（へだ）てなき
明治（めいぢ）の光（ひか）り隈（くま）もなく
臺灣島（たいわんたう）に輝（かゞや）きし
譽（ほまれ）を歌（うた）へ萬歳（ばんざい）に。

三　昔（むかし）の御代（みよ）に例（ためし）なき
よき日（ひ）は今日（けふ）のよき日（ひ）なり。
萬（よろづ）の國（くに）に轟（とゞろ）きし
譽（ほまれ）は今日（けふ）の譽（ほまれ）なり。
```
