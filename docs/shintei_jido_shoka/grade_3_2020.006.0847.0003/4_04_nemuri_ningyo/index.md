```text
泣いて　お目々を閉ぢますの

二
夢にはイギリス　ロンドンの
ショウヰンドウの中にゐた
去年の秋を見てませうか
私の仲よしのおばさまに
買はれた時の夢でせうか
私　おこして　やりませうか

三
それとも　お船に乗せられて
遠い日本へ送られた
長道中の夢でせうか
淋しい淋しい夢でせうか
それなら起してやりませう
起して　遊んでやりませうか

四
それとも　おくにでロンドンで
金髪　青眼で　丸顔で
赤頬ぺたの友達と
夢で遊んでゐませうか
それなら　もつともつと寝かしませう
寝かして　その夢　見せませう
```
