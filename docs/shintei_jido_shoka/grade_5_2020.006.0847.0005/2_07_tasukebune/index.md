```text
一　はげしき雨風　天地くらく
山なすあら波たけり狂ふ
見よ見よかしこにあはれ小舟
生死のさかひと救もとむ

二　救を求むる　聲はすれど
この風この波誰もゆかず
見よ見よこぎづるすくひ小舟
けなげのをのこら守れ神よ
```
