```text

耕（たがや）し蠶飼（こが）ひ、雞（とり）をかひ

村人すべて　樂しみ暮す

二　平和なる村、我等の村よ
村長（むらをさ）よくして師弟（してい）は愛し
青年團は、植林（しよくりん）をなす
我等の村は　彌榮（いやさか）ゆなり
```
