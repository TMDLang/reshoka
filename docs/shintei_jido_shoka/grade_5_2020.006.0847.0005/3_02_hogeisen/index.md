## 歌詞

```text
一　波をば切りて　進み行く
勇まし／＼　捕鯨船（ほげいせん）
指ざす北の方海の上（へ）はるか
あがるよ／＼水煙（みづけむり）白く
たしかに鯨のしほをはく
波をば切りて　進み行く
勇まし／＼　捕鯨船
ねらひを定めてずどんと一發（ぱつ）
もりをばしかけてはなつ破裂矢（はれつや）
もう／＼立ちこむ白煙（しろけむり）

二　或は高く　又低く
進むも勇まし　捕鯨船
うち出すはれつ矢はみごとにあたり
うかぶよ沈むよ荒れ狂ふくぢら
かいくるをづなにひかれつつ
或は高く　又低く
進むも勇まし　捕鯨船
血しほはながれ出で山なす鯨
いきほひうすれて水の面（おも）に横たふ
萬歳　船人（ふなびと）　萬々歳
```
