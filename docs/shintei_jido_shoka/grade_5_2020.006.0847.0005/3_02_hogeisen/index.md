```text
もう／＼立ちこむ白煙（しろけむり）

二　或は高く　又低く
進むも勇まし　捕鯨船
うち出すはれつ矢はみごとにあたり
うかぶよ沈むよ荒れ狂ふくぢら
かいくるをづなにひかれつつ
或は高く　又低く
進むも勇まし　捕鯨船
血しほはながれ出で山なす鯨

萬歳　船人（ふなびと）　萬々歳
```
