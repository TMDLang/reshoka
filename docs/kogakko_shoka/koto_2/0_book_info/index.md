# 書訊與卷首／卷末掃描頁 — 《公學校唱歌》 高等科 第二學年用（國臺圖 0729 74）

本頁收錄本冊之封面、扉頁、目次（もくろく）、樂典大要、版權頁與封底等原書掃描圖檔（共 3 頁）。

### P001.jpg

本冊封面（右頁），題「公學校高等科唱歌　第二學年用　臺灣總督府」，中央繪有朱紅相思樹葉與飛鳥圖案，左上貼有舊藏圖書分類籤「0729 74」，下方貼有國立臺灣圖書館條碼籤「3 1111 004775670」。

![《公學校唱歌》 高等科 第二學年用（國臺圖 0729 74） 原書掃描頁 P001.jpg](P001.jpg)

### P002.jpg

扉頁，題「公學校高等科唱歌　第二學年用　臺灣總督府」，上方蓋有「臺灣總督府圖書館藏」方形大印，左下蓋有「昭和十一年六月二十九日　編修課ヨリ寄贈」藏書印，右下蓋有「已製影本」紅印。

![《公學校唱歌》 高等科 第二學年用（國臺圖 0729 74） 原書掃描頁 P002.jpg](P002.jpg)
