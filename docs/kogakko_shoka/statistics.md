# 《公學校唱歌》統計專題

## 一、先說結論

目前 Re:shoka 的 `kogakko_shoka` 資料集收錄《公學校唱歌》尋常科第一至第六學年，以及高等科第一、二學年的 **8 冊、155 首曲譜**。從曲目結構來看，這套教材不是把歌曲任意分冊，而是呈現出相當清楚的學習梯度：

- 尋常科第一學年以二拍子、F／D 調與五聲音階歌曲為主；
- 隨年級上升，四拍子、三拍子與六八拍逐步增加；
- 五聲音階在低年級幾乎是整體語法，高等科則讓位給較多七聲自然音階與變化音；
- 155 首中有 **91 首（58.7%）** 屬於廣義五聲音階，顯示五聲性仍是全套教材的重要底層語彙；
- 有 **71 首（45.8%）** 能在 Re:shoka 其他教材中找到同曲或同一傳承曲目，說明《公學校唱歌》同時具有「新編教材」與「既有唱歌教材匯集」兩種性質。

因此，這套資料最值得觀察的，不只是單首歌曲，而是它如何把旋律難度、節奏型態、音階材料與教材用途分配到不同學年。

## 三、曲數如何分配：高年級每冊容量明顯增加

尋常科前三冊各收 15 首，第四至第六學年各收 20 首；高等科兩冊則各收 25 首。這個分配本身就透露出教材設計的差異：低年級以短小、集中、可反覆練唱的課次為主；進入高年級後，歌曲數量增加，同時也加入合唱、輪唱、儀式性與較具敘事性的曲目。

| 階段 | 冊數 | 曲數 | 佔全體 |
| :--- | ---: | ---: | ---: |
| 尋常科第一至三學年 | 3 | 45 | 29.0% |
| 尋常科第四至六學年 | 3 | 60 | 38.7% |
| 高等科第一至二學年 | 2 | 50 | 32.3% |

## 四、拍號與速度：從二拍子童謠走向較寬的節奏世界

全體以四拍子最多，共 75 首（48.4%）；二拍子 56 首（36.1%）；三拍子 16 首（10.3%）；六八拍 8 首（5.2%）。平均速度為 **99.7 BPM**，中位數 100 BPM。

| 拍號 | 曲數 | 佔全體 | 平均速度 |

| 3/4 | 16 | 10.3% | 99.7 BPM |

這裡有一個很清楚的編排方向：低年級先用二拍子建立穩定的步行、口語與童謠律動；高年級則以四拍子為骨架，加入三拍子與六八拍，要求學生處理更長的樂句、較複雜的重音與不同的律動感。六八拍平均速度較低，也符合它常被用於歌唱性較強、搖曳或敘事性的曲目。

## 五、調性：以易唱的中小調號為中心

曲譜標示的調號集中在八種調性，最常見的是 F、C、G、D 與 E♭：

| 調號 | 曲數 | 佔全體 |
| :--- | ---: | ---: |
| F | 38 | 24.5% |
| C | 27 | 17.4% |
| G | 25 | 16.1% |
| D | 23 | 14.8% |
| E♭ | 20 | 12.9% |
| B♭ | 11 | 7.1% |
| A | 6 | 3.9% |
| E | 5 | 3.2% |

依目前 TMD 的調性診斷，155 首中有 **141 首（91.0%）判定為大調**，14 首（9.0%）判定為小調。這不是說教材沒有情緒變化，而是它多半透過速度、節拍、旋律走向、歌詞題材與和聲配置來製造差異，而不是大量採用小調。

## 六、音階型態：五聲音階是低年級的核心語法

以旋律中實際出現的音級與時值比例分類：

| 音階型態 | 曲數 | 佔全體 |
| :--- | ---: | ---: |
| 嚴格五聲音階（不超過五個音級） | 45 | 29.0% |
| 準五聲音階（核心五聲佔時值至少 95%） | 46 | 29.7% |
| **廣義五聲音階合計** | **91** | **58.7%** |
| 六聲音階 | 12 | 7.7% |
| 七聲自然音階 | 34 | 21.9% |
| 含變化音之七聲以上音階 | 18 | 11.6% |

更重要的是它與年級高度相關：

| 冊別 | 廣義五聲音階 | 七聲自然音階 | 含變化音音階 |
| :--- | ---: | ---: | ---: |
| 尋常科第一學年 | 15／15（100.0%） | 0 | 0 |
| 尋常科第二學年 | 14／15（93.3%） | 1 | 0 |
| 尋常科第三學年 | 13／15（86.7%） | 2 | 0 |
| 尋常科第四學年 | 16／20（80.0%） | 2 | 0 |
| 尋常科第五學年 | 9／20（45.0%） | 4 | 3 |
| 尋常科第六學年 | 9／20（45.0%） | 7 | 2 |
| 高等科第一學年 | 11／25（44.0%） | 9 | 4 |
| 高等科第二學年 | 4／25（16.0%） | 9 | 9 |

這組數字是本資料集最具教育史意義的結果之一。第一學年所有曲目都落在廣義五聲音階範圍內；到了高等科第二學年，只剩 4 首。換句話說，教材把「音級材料的擴張」安排成一條大致可見的學習曲線：先熟悉五聲骨架，再逐步引入 Fa、Ti、自然七聲音階，以及臨時升降音或局部轉調。

需要注意的是，這不是「日本教材從東方音階進步到西方音階」的單線故事。資料中仍有大量高年級五聲性歌曲，而低年級也不是完全沒有外來曲調。比較穩妥的說法是：教材在不同學年之間調整五聲性與七聲性材料的比例，讓學生逐步擴大可處理的旋律範圍。

## 七、與其他教材的重複：一套教材也是一張傳承網

在目前 `duplicate_songs` 的同曲群組中，`kogakko_shoka` 有 **71 首**被辨識為可與 Re:shoka 其他教材對照的同曲，約佔本資料集 **45.8%**。這些不是「不重要的重複」，而是教材流通與曲目傳承的證據。

其中可見幾類現象：

- **文部省唱歌與常見童謠的延續**：如〈ヒノマル ノ ハタ〉、〈ハト〉、〈カタツムリ〉、〈ツキ〉、〈イヌ〉、〈モモタラウ〉等，在不同年代、不同教材中反覆出現；
- **儀式、國家與軍事歌曲的跨教材流通**：如〈大日本〉、〈日本海海戰〉、〈我が帝國〉、〈明治天皇御製〉等；
- **臺灣地方題材的教材化**：如〈水牛〉、〈おまつり日〉、〈赤嵌城〉等，顯示《公學校唱歌》不只搬用既有曲目，也把臺灣地方題材納入學校唱歌系統；
- **高等科的共同曲目**：〈去年今夜〉、〈子守歌〉、〈大和魂〉、〈青年の歌〉、〈朝風〉等，顯示高等科教材與其他近代唱歌集之間有更密切的共享關係。

這也說明「同名」與「同曲」必須分開處理：本頁所引用的是同曲／同一傳承群組的統計，不把僅僅同名但旋律不同的歌曲當作同一首。對教材史而言，重複歌曲不代表編者缺乏創意，而是可以用來追蹤哪些歌曲被認為值得跨年級、跨版本、跨教材保存。

## 九、研究上的幾個觀察

### 1. 曲數增加不等於只是在「塞更多歌」

從 15 首增加到 20、25 首的同時，節拍與音階材料也變得更寬。高等科曲目較多，部分原因正是歌曲功能變得多樣：除了日常練唱，也包括輪唱、合唱、儀式、歷史敘事與較成熟的抒情歌曲。

### 2. 五聲音階不是整套教材的單一風格，而是入門層與持續存在的骨架

低年級的五聲性非常集中，但到了高等科，仍有不少歌曲保留五聲骨幹。它比較像一種可供學生快速掌握的旋律資源，而不是只屬於某個時代或某一類題材的標籤。

### 3. 《公學校唱歌》同時包含「標準曲目」與「臺灣在地編纂」

同一套教材裡，既有文部省唱歌、長期流傳的童謠與軍歌，也有以芒果、檳榔、八哥、水牛、白鷺鷥、赤嵌城等臺灣經驗為題材的新編作品。統計資料因此應與作詞者、編者、原書頁面及歌詞史料一起讀，不能只看旋律數值。

### 4. 這份統計首先是資料品質的觀測工具

目前數字建立在 TMD 轉錄與 metadata 之上。只要某一首的拍號、調號或音符轉錄有誤，統計就會跟著偏移。因此本頁適合用來發現異常、提出研究問題與安排校譜優先順序，不能把它當成已完成的樂譜定本。

## 十、後續可以怎麼用

這份統計可以作為三種工作的入口：

1. **校譜優先排序**：優先檢查會改變年級趨勢的曲目，例如低年級被判定為非五聲、或高等科出現罕見拍號的曲目。
2. **教材比較**：把《公學校唱歌》與《尋常小學唱歌》、《新定兒童唱歌》等教材放在同一尺度上，比較不同編纂者如何安排五聲性、調號與拍號。
3. **曲目傳承研究**：從 71 首跨教材同曲出發，逐首核對旋律、歌詞、調性、節拍與版本年代，將「同曲」與「同名異曲」分開建立可靠的傳承鏈。

總的來說，`kogakko_shoka` 最有價值的地方，不只是它收集了 155 首曲譜，而是它把一套完整的學年制唱歌教材呈現成可比較、可追蹤、也可持續校正的資料。它讓我們看到：近代臺灣的學校唱歌教育，如何從低年級的可唱性與五聲骨架，逐步走向高年級較寬廣的節奏、音階與教材功能。
