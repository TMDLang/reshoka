## 說明

原書資訊與註解（國臺圖 0786 6《蕃人ノ音樂 第二集・アミ族蕃謠歌曲》第八首，掃描 P008.jpg）：
曲名：老蕃粟刈祝の歌（紅座社）
調性與拍號：降乙調（B♭ 大調）／變格移拍 2/4、3/4 與 4/4 拍子
音樂形式：長老領唱（音頭／獨唱）與族人應和（齊唱）之二部應答與重疊合唱（Antiphony / Two-part chorus）


## 歌詞

```text
原書頁底註記：
「老蕃美聲ナル者音頭ヲナシ獨唱ノ部ヲ歌フ
歌詞ナク上記ノ發音ノミヲ用フ」

【中譯解說】
阿美族紅座社部落之年老原住民中歌聲優美者擔任領唱（音頭），專責演唱「獨唱」聲部（Piano1），
其餘族人則以「齊唱」應和（Piano2）。在 System 2 與末段 System 6–8，齊唱更與獨唱重疊發聲，
形成壯麗的二部合唱。全曲無實質文義之歌詞，純粹以假名記錄之虛詞／襯字音節吟唱。
```
