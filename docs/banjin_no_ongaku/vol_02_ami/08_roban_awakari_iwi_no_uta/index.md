## 說明

原書資訊與註解（國臺圖 0786 6《蕃人ノ音樂 第二集・アミ族蕃謠歌曲》第八首，掃描 P008.jpg）：

音樂形式：長老領唱（音頭／獨唱）與族人應和（齊唱）之應答對唱（Antiphony）


## 歌詞

```text
原書頁底註記：
「老蕃美聲ナル者音頭ヲナシ獨唱ノ部ヲ歌フ
歌詞ナク上記ノ發音ノミヲ用フ」

【中譯解說】
阿美族紅座社部落之年老原住民中歌聲優美者擔任領唱（音頭），專責演唱「獨唱」聲部，
其餘族人則以「齊唱」應和。全曲無實質文義之歌詞，純粹以假名記錄之虛詞／襯字音節吟唱。
本曲為單旋律順序轉錄版，若欲欣賞長老與族人和聲重疊之二部合唱，請參閱《二部合唱版》（roban_awakari_iwi_no_uta_piano.tmd）。
```
