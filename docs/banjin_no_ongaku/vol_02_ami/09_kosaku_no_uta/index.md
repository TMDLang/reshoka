## 說明

原書資訊與曲目說明：
出處：《蕃人ノ音樂 第二集・アミ族蕃謠歌曲》（大正14年／1925年11月，臺灣教育會發行）
曲名：耕作の歌
踏查與採集部落：舞鶴社（花蓮港廳管下，今花蓮縣瑞穗鄉舞鶴村）
採譜者：一條愼三郎（臺北師範學校教諭）
調性與拍號：變ホ調記譜（3 個降記號 ♭，E♭ 調記譜，實質為 C 羽調式／C 小調原住民族三音歌謠，核心骨幹音 C - E♭ - G），四分之四拍子（4/4 拍）
原書頁底註解（日文原文）：
「耕作集會其他何ノ場合ニモ用フ」
「歌詞ナク上記ノ發音ノミヲ用フ」
【註解中譯】
本曲於耕作、部落集會及其他任何場合均可詠唱使用。
全曲無固定之敘事歌詞，僅詠唱五線譜下記錄之片假名虛詞／襯詞發音。
