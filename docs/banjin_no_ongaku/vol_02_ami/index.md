# 《蕃人ノ音樂》 第二集・アミ族蕃謠歌曲（大正14年／1925，國臺圖 0786 6）

> 國立臺灣圖書館「日治時期圖書影像系統」典藏號 **`jpli2024-bk-sxt_0786_6_1925`**（索書號 **`0786 6`**，登錄號 **`31111004748586`**）。大正 14 年（1925 年）11 月**臺灣教育會**發行（臺北師範學校教諭**一條愼三郎**實地採譜編纂）。為日治時期臺灣原住民族傳統音樂實地田野調查採集與五線譜表記之劃時代開創性文獻《蕃人ノ音樂》第二集。全冊收錄花蓮港廳與臺東廳阿美族 **6 大社群**（馬蘭社、下朥灣社、紅座社、舞鶴社、奇密社、太巴塱社）共 **14 首**傳統歌謠，涵蓋耕作歌、豐年祭歌舞、迎賓、粟刈祝祭、正月首祭與酒宴歌，生動記錄原住民珍貴之虛詞吟唱、領唱答唱（Call and Response）以及自由對位複音結構。
