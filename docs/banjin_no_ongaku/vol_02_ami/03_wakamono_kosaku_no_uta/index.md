## 歌詞

```text
原書頁底註記：
「生＝青年ガ耕作ノ時又ハ酒宴ノ時歌フ
歌詞ナク上記ノ發音ノミヲ用フ」
（原譜左緣完整文字：「青年ガ耕作ノ時又ハ酒宴ノ時歌フ／歌詞ナク上記ノ發音ノミヲ用フ」）

【中譯解說】
馬蘭社（今臺東市馬蘭部落）青年於田間耕作勞動時，或聚會酒宴時所唱之歌。
全曲無固定實詞義理，純粹以樂譜上表記之假名虛詞音節（襯字）吟唱，音型質樸流暢，節奏充滿田間勞作與宴飲應和之律動感。
```
