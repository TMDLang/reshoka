## 序文、引言與地圖扉頁（日文原文轉錄與中譯）

### 序（臺灣教育會）

> 本會嘗に「水社化蕃の歌」を公刊せり、蓋し本島蕃族の研究資料の一として速かに其の音樂を蒐集する事を必要と信じたればなり。
> 今又茲にアミ族の歌謠を蒐めて一集となす事を得たり、これ主として臺北師範學校教諭一條愼三郎君の努力に依る。
>
> 大正十四年十一月　　臺灣教育會

**【中譯】**
本會先前曾出版《水社化蕃之歌》，蓋因深信及早蒐集本島各原住民族之音樂，實為蕃族研究不可或缺之首要資料。
今又得以採集阿美族之歌謠彙集成冊，此成果主要歸功於臺北師範學校教諭一條愼三郎君之戮力以赴。
大正十四年十一月　臺灣教育會

### 引（前言）

> アミ族は花蓮港臺東兩廳下の平地一帶に集團占居せる蕃族にして總人口約四萬夙に農耕を業とし又勞役にし性質溫和風俗淳厚蓋し本島蕃族中最も進化せる大種族なり。就中薄々社 太巴塱社 奇密社 馬蘭社の如き蕃屋集まり田園開けて內地の農村に髣髴たるものあり。彼等の音樂を好むは天性に依るものゝ如く老若男女を論ぜず時々相集まり圓陣を作り手を翳し足を振り美音を張り上げて合唱し頸と手足に結べる鈴の音と相和して雅趣掬すべく其の圓陣も大となり小となり右に進み左に還り亂舞の如くして而も歌曲と共に一定秩序の存するを見る。然れども內臺人との接觸最も頻繁なるがため漸次歌曲に變化を及ぼし其の天眞素朴を失はんとする勢に在るは惜むべし。一條愼三郎君は本會の囑を受けて親しく彼の地を訪ひ馬蘭社 紅座社 奇密社 太巴塱社等を廻り二週間の日字を費して彼等の歌謠を作譜し尙又其の一部は寫音機を以て吹込む事に成功せられたり。本書に收むる歌曲は其の數十四アミ族の歌謠中最も純粹にして且つ代表的のものなりとす。

**【中譯】**
阿美族乃聚居於花蓮港、臺東兩廳管下平地一帶之原住民族，總人口約四萬人，自古即以農耕為業並服勞役，性格溫和、風俗淳厚，堪稱本島原住民族中發展程度最高之大族。其中如薄薄社、太巴塱社、奇密社、馬蘭社等處，聚落房舍鱗次櫛比、田園沃野廣袤，景致令人聯想起日本內地之農村。彼等嗜好音樂若出天性，不拘老幼男女，時常相聚圍成圓陣，揚手頓足、引吭高歌放聲合唱，與繫於頸項及手足之鈴聲相互應和，雅趣盎然。其圓陣忽大忽小、右旋左轉，看似亂舞卻隨歌曲節奏井然有序。然而，由於與內地人及本島漢人之接觸日趨頻繁，歌謠漸受外來影響而產生變異，其天真質樸之風貌恐有漸趨泯滅之虞，良深惋惜。一條愼三郎君受本會之託，親自走訪其地，踏查馬蘭社、紅座社、奇密社、太巴塱社等部落，歷時二週為其歌謠記譜，並成功以錄音機（寫音機）灌錄部分音訊。本書所收錄之十四首歌曲，堪稱阿美族歌謠中最純粹且最具代表性之珍品。
