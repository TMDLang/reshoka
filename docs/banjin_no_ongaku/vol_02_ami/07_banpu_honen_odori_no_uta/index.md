## 歌詞

```text
原書頁底註記：
「蕃婦集會シテ粟祭收穫祭ニ歌フ
歌詞ナク上記ノ發音ノミヲ用フ」

【中譯解說】
阿美族婦女聚會時，於粟祭（小米祭）及收獲祭（豐年祭）時所唱之歌。
全曲無固定實詞文義，純粹以假名記錄之虛詞／襯字音節吟唱應和。
```
