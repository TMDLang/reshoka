## 說明

出版：臺灣教育會（大正十四年十一月）
【原書說明與中譯】
原書腳註說明：「山野ニテ耕作牛飼ノ時又ハ多數集合共同作業ノ時等歌フ、歌詞ナク只本曲ニ記載ノ如キ發音ノミヲ用フ」
（中譯：於山野間從事耕作、放牧水牛之時，或眾人集結進行共同作業之際所演唱。並無具體語意之歌詞，僅使用如本曲所記載之片假名虛詞發音。）
