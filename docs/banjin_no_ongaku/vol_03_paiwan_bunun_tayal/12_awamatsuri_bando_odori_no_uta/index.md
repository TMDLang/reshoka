## 說明

原書資訊與曲目說明（國臺圖 0786 7a《パイワン族 ブヌン族 タイヤル族蕃謠歌曲》第十二曲，掃描 P014.jpg）：
標題：粟祭蕃童踴の歌（太麻里社）
社群：太麻里社（Tjavualji，排灣族巴卡羅群／太麻里部落，今臺東縣太麻里鄉）
調性與拍號：ヘ調（F 大調 / 傳統羽調式・宮調式五聲音階）四分ノ二拍子（2/4）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
版畫插圖：樂譜上方繪有身著傳統盛裝短裙、斜披佩帶與頭冠之排灣族少年，以及後方歡樂牽手跳舞的人群。
【原書說明與中譯】
原書腳註說明：「粟祭ノ時主ニ蕃童ノ踴ニ用フ
アイヤオエは發音のみ「頭目さんよあなたの若者は、山猪をとりに行つても取れないし、又山猪に逢ひもしませんね」の意なるも、其中には私達少年が行つたら吃度取れますよといふ事を含みをり、即ち青年よりも少年の方が偉いものであるとの意味」
（中譯：主要於小米祭之際，提供蕃童（少年）跳舞時所演唱。
「アイヤオエ」為虛詞發音。歌詞大意為：「頭目先生啊！您手下的那些青年，去打山豬也打不到，甚至連山豬的影子都碰不著呢！」但言下之意其實隱含著：「若是換作我們少年出馬，一定能手到擒來抓到山豬！」也就是表達少年比青年更為優秀神勇的詼諧較勁之意。）
