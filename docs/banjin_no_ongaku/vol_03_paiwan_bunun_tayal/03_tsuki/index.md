## 說明

原書資訊與曲目說明（國臺圖 0786 7《パイワン・ブヌン・タイヤル族蕃謠歌曲》第三曲，掃描 P005.jpg）：
標題：月
副標題：卑南知本兩社共通童謠の一
調性與拍號：ニ調（D 大調 / 傳統羽調式・律音階）四分之四拍子（Common Time, C / 4/4）
演唱形式：音頭（領唱 / Solo Leader，第 1–2 小節）與齊唱（合唱 / Tutti Chorus，第 3–7 小節）之呼應形式（Call and Response）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月）
【原書說明與中譯】
原書腳註說明：「男女蕃童月明庭前ニ莚ヲノベ座シテ歌フヲ常トス」
（中譯：每逢月明之夜，原住民男女蕃童常於庭前鋪設草蓆席地而坐，圍坐歌唱此曲。）
