## 說明

原書資訊與曲目說明（國臺圖 0786 7《パイワン・ブヌン・タイヤル族蕃謠歌曲》第二曲，P003–P004）：
標題：護鄉兵凱旋の歌（卑南社）
部落社群：卑南社（臺東廳卑南社，今臺東市南王部落，卑南族 Puyuma 傳統大社；日治初期臺灣總督府調查多將卑南族劃入排灣群）
調性與拍號：G 調記譜五聲音階（傳統羽調式 / 6_ 1 2 3 5 6，以 E4 為主音結尾），四四拍（4/4）
音樂形式：應答唱形式（音頭＝獨唱 / Solo，齊唱 / Chorus）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
【原書說明與中譯】（P004.jpg 底欄註記）
原書腳註說明：
「數十年前卑南蕃嘉義方面ノ土匪ト戰ヒ大勝凱旋ノ時歌ヒシ曲
本歌詞第一ノ大意：射擊の音は鈴の樣で非常に面白かつた敵の方より來る臭氣は心地よく思つたがその首を見ては悲しい思ひをした
第二、三、四歌ハ即興ニ附セシモノ其ノ大意：我々は歌は大變好きであるが特に今日此處でこの歌を歌ふのを非常に嬉しく愉快に思ふ
各歌三、四段ハ發音ノミ」
中文語譯：
「數十年前卑南社勇士與嘉義方面之土匪交戰，大獲全勝凱旋之時所歌唱之曲。
本歌詞第一節大意：槍砲射擊之聲宛如清脆鈴響，令人備感振奮有趣；迎風襲來敵方的氣味令人感到暢快，然而望見砍下的首級時，心中卻也湧起悲涼的感觸。
第二、三、四節為即興配唱之歌詞，其大意為：我們平時極為熱愛歌唱，尤其今日能在此處高唱此曲，心中更感到無比歡欣與暢快。
各節歌謠之第三、四段（Staff 3 與 Staff 4）均為無固定字義之虛詞發音。」
