## 說明

原書資訊與曲目說明（國臺圖 0786 7a《パイワン族蕃謠歌曲》第六曲，掃描 P008.jpg）：
標題：粟祭の歌（知本社）
調性與拍號：變ロ長調記譜（2 個降記號 ♭，B♭ 調記譜 / 羽調式・商調式原住民族音階，中心音 C/G）二分ノ二拍子（2/4）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
【原書說明與中譯】
原書腳註說明：「男女耕作、粟祭等ニ用フ
歌詞前半ハ隨時即興　後半アリワン以下ハ意味ナキ發音ノミヲ用フ
本歌詞前半ノ大意ハ
｛我々は歌ふことが大好で特にこの臺東へ來て歌ふのは非常に喜ばしいしかしもう大分歌つたからこれでやめにしませう」
（中譯：男女於農事耕作、舉行粟祭等場合演唱。歌詞前半段為隨時即興創作，後半段「アリワン」以下則僅使用無具體語意之襯詞發音。本曲所錄歌詞前半段之大意為：「我們非常喜愛歌唱，尤其是能來到這臺東歌唱更是無比歡喜；不過已經唱了許久，就唱到這裡告一段落吧。」）
