## 說明

原書資訊與曲目說明（國臺圖 0786 7《パイワン・ブヌン・タイヤル族蕃謠歌曲》第四曲，掃描 P006.jpg）：
標題：集會所
副標題：卑南社知本社共通童謠の二
調性與拍號：イ調（A 大調 / 傳統五聲音階）四分之四拍子（4/4）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月）
【原書說明與中譯】
原書腳註說明：「八社蕃ハ八九歲ノ頃ヨリ青年期ニ至ルマデ男兒ハ自宅ニ寢ヌルコト能ハス集會所ニテ就眠ノ習慣アリ其時歌フ曲ナリ」
（中譯：卑南八社原住民男童自八、九歲起至青年期為止，依習俗不得於自宅就寢，而有集中於青年集會所（palakuan / 会所）過夜睡眠之習慣，此曲即為當時所唱之歌謠。）
