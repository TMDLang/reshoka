## 說明

原書資訊與曲目說明（國臺圖 0786 7《蕃人ノ音樂 第三集》第七曲，掃描 P009.jpg）：
標題：首祭酒宴の歌（知本社）
調性與拍號：無升降記號（ハ調記譜 / C 大調五聲羽調式音階）四分ノ四拍子（4/4）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
採集地點：臺東廳知本社（Katratripulr，今臺東縣臺東市知本部落，卑南族卡大地布部落，日治初期官方常劃於排灣族範疇）
【原書說明與中譯】
原書腳註說明：「首祭リノ後、或ハ平常ニモ男女トモ只座シテ酒ヲ呑ミツツ歌フ
歌詞ハ即興的ニ作ッテ歌フコトアルモ本曲ニハ只發音ノミヲ附シタリ」
（中譯：於獵首祭之後，或平常男女圍坐飲酒之際所演唱。歌詞有時雖會即興創作演唱，但本曲僅附上片假名虛詞發音標記。）
【音樂結構分析】
全曲為 4/4 拍，共 10 小節，旋律由 C4, E4, G4, A4, B4, D5 等音構成（五聲音階宮羽調式），節奏充滿切分與附點律動：
- 第一段（Staff 1，m.1–m.3）：酒宴開場吟唱，以五度跳進與十六分音符附點襯字開展。
- 第二段（Staff 2，m.4–m.6）：長音延展「ヤイヤーン」接續「イヨホホホイ」的高音跌宕。
- 第三段（Staff 3，m.7–m.10）：旋律沉著回旋，最終終止於主音 1（C4），結構嚴謹完整。
