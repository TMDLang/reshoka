## 說明

原書資訊與曲目說明（國臺圖 0786 7《パイワン族、ブヌン族、タイヤル族蕃謠歌曲》第十曲，掃描 P012.jpg）：
標題：粟祭結婚式等の歌（知本社）
調性與拍號：變ロ調系 / ハ短調（C minor / C Dorian / 徵羽調式五聲音階 C-D-F-G-Bb），四分ノ四拍子（4/4 拍，記為 C）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月）
音樂形式：三段歌詞（Verse 1–3）附唱反覆曲式（Refrain），包含本歌唱詞與歌末襯詞附唱
【原書說明與中譯】
原書腳註說明：
「朝、野邊＝集合ノ時、粟祭ノ時、結婚ノ時等＝用フ」
「歌詞ハ即興的ニ附シ各歌終リニ發音ノミヲ附シ反覆シテ歌フ」
「本歌詞ノ大意：この清らかな今朝此處に集まつたのを幸ひ楽しく面白く歌ひませう」
（中譯：於清晨在野外集合之時、舉行粟祭（小米祭）之際、或結婚典禮等喜慶場合歌唱。
歌詞通常為即興作詞，每一首本歌唱畢後，皆附加上純發音之虛詞／襯詞段落並反覆詠唱。
本譜記載歌詞之大意：「有幸在這清朗的今晨聚集在此處，讓我們歡欣快活、趣味盎然地歌唱吧！」）
