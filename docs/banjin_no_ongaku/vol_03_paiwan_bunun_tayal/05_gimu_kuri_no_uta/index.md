## 說明

原書資訊與曲目說明（國臺圖 0786 7a《パイワン族蕃謠歌曲》第五曲，掃描 P007.jpg）：
標題：義務苦力の歌（卑南社知本社共通童謠之三）
調性與拍號：ハ長調記譜（無升降記號，C 大調 / 宮調式五聲音階）二分ノ二拍子（2/4）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
【原書說明與中譯】
原書腳註說明：「蕃童等頭目ヨリ仕事ヲ命ゼラレ空腹ニナルモ思フ樣食事スルコト能ハズ三十日餘モ義務的ニ勞作ヲ餘儀ナクセラルル稍不滿ヲ歌ヒシモノ」
（中譯：番社孩童受到頭目派任工作勞役，即便飢腸轆轆亦無法隨心所欲用餐，三十多天被迫從事義務性勞作，此曲即為抒發心中稍許不滿情緒之童謠。）
