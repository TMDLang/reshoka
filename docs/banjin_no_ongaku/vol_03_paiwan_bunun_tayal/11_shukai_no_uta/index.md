## 說明

原書資訊與曲目說明（國臺圖 0786 7a《パイワン族 ブヌン族 タイヤル族蕃謠歌曲》第十一曲，掃描 P013.jpg）：
標題：集會の歌（知本社）
社群：知本社（Katratripulr，原書編入排灣族歌曲，歷史人類學亦多指今卑南族知本部落）
調性與拍號：ヘ調（F 大調）四分ノ四拍子（4/4）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
【原書說明與中譯】
原書腳註說明：「集會遊戲ノ時主ニ用フ
歌詞隨時即興
本歌詞ノ大意：
〔この木の下の涼しい所で今集まつた時、何もしないで居るよりも、お互に歌つて遊びませう、何か思つた時は遠慮なしにかくさず歌つて面白く遊びませう」
（中譯：主要於部落集會、遊戲娛樂之時演唱。歌詞隨時即興創作。
本歌詞大意：在這一片涼爽的樹蔭下，如今大家相聚之時，與其什麼都不做枯坐著，不如大家一起唱歌同樂吧！心中想到什麼，就毫無顧忌、毫不隱瞞地唱出來，暢快歡樂地玩耍吧！）
