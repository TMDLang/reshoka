## 歌詞

```text
【原書說明與中譯】
原書腳註說明：
「集會遊戯ノ時主ニ用フ
歌詞隨時即興
本歌詞ノ大意：この木の下の涼しい所で今集まつた時、何もしないで居るよりも、お互に歌つて遊びませう、何か思つた時は遠慮なしにかくさず歌つて面白く遊びませう」

中文語譯：
「於集會遊戲娛樂時主要唱之歌曲。
歌詞隨興即興編唱。
本記錄歌詞大意：如今我們大家相聚在這大樹下的陰涼之處，與其無所事事呆坐著，不如大家互相歡唱同樂吧！心中若有任何感想，請毫無保留、暢所欲言地唱出來，讓我們開開心心痛快玩耍吧！」
```
