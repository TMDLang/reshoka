# 《蕃人ノ音樂》 第三集・パイワン・ブヌン・タイヤル族蕃謠歌曲（大正14年／1925，國臺圖 0786 7）

> 國立臺灣圖書館「日治時期圖書影像系統」典藏號 **`jpli2011-bk-sxt_0786_7_1925`**（索書號 **`0786 7`**，登錄號 **`31111004748578`**）。大正 14 年（1925 年）11 月 25 日**臺灣教育會**發行、株式會社**臺灣日日新報社**印行（臺北師範學校教諭**一條愼三郎**著／實地採譜）。為日治時期臺灣原住民族傳統音樂實地田野調查採集與五線譜表記之劃時代開創性文獻《蕃人ノ音樂》第三集。全書共收錄 **16 首**珍貴歌謠：主體為臺東廳轄下排灣族（含卑南群）之**卑南社**（2 首）、**卑南與知本兩社童謠**（3 首）、**知本社**（6 首）、**太麻里社**（2 首）共 13 首，並於卷末附錄花蓮港廳玉里支廳之**布農族卓溪社**（2 首）與**泰雅族太魯閣社**（1 首）。生動記錄了臺灣東部原住民族的小米祭、獵首祭、童謠、共同勞役與耕作酒宴歌謠之原始古風與多樣化音階體系。
