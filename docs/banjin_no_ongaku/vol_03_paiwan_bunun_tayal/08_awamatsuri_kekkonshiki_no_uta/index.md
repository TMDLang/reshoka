## 說明

原書資訊與曲目說明（國臺圖 0786 7《蕃人ノ音樂 第三集》第八曲，掃描 P010.jpg）：
標題：粟祭結婚式の歌（知本社）
調性與拍號：1 個降記號（ヘ調記譜 / F 大調五聲宮調式音階）四分ノ四拍子（4/4），弱起（Anacrusis / 1 拍起奏）
採譜：一條愼三郎（臺北師範學校教諭，大正十四年／1925 年實地採集記譜）
出版：臺灣教育會（大正十四年十一月二十五日發行）
採集地點：臺東廳知本社（Katratripulr，今臺東縣臺東市知本部落，卑南族卡大地布部落，日治初期官方常劃於排灣族範疇）
【原書說明與中譯】
原書腳註說明：「八月頃粟祭リノ時又ハ結婚ノ時ニモ用フ
歌詞ナク上記ノ發音ノミヲ附ス」
（中譯：約於八月小米收穫祭之時，或結婚典禮之際所演唱。並無具體語意之歌詞，僅附上上述片假名虛詞發音標記。）
【音樂結構分析】
全曲為 4/4 拍弱起歌謠，由 1 拍弱起小節與 12 小節旋律構成（終止小節為 3 拍以補足弱起），主要音高涵蓋 F4, A4, C5（宮、角、徵三音核心，偶現跳進），具有強烈儀式性與慶祝宴樂之重拍節奏感：
- 弱起與第一段（Staff 1，m.0–m.3）：以「ヘ」弱起跳進展開，歡樂呼喊慶賀。
- 第二段（Staff 2，m.4–m.6）：休止符與應答襯字「ヤン　ヘー」形成呼應。
- 第三段（Staff 3，m.7–m.9）：同音反覆唱誦「ホンヘヨヘヨホ」，氛圍熱烈莊重。
- 第四段（Staff 4，m.10–m.12）：齊聲唱和「アイホアィホアィホ」與尾聲結音，以「ハウハイ」乾脆有力地收束於主音 1（F4）。
