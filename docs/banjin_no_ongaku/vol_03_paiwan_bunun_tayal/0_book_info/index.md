## 序文、引言與版權頁（日文原文轉錄與中譯）

### 序（臺灣教育會）

> 本集は「蕃人の音樂」第三集として臺東廳下に於けるパイワン族の歌謠を輯錄し尙終にブヌン族(卓溪社)のもの二種タイヤル族(太魯閣蕃)のもの一種を添へたり。
> 卽ち前集「アミ蕃の歌」を加へて東部臺灣に於ける蕃人の歌謠は其の一班を盡せるものなり。歌謠の調査整理は主として臺北師範學校敎諭一條愼三郎君の努力に依る。
>
> 大正十四年十一月　　臺灣敎育會

**【中譯】**
本集作為《蕃人之音樂》第三集，輯錄臺東廳轄下排灣族之歌謠，並於卷末附錄布農族（卓溪社）二種、泰雅族（太魯閣蕃）一種。合前集《阿美蕃之歌》觀之，東部臺灣原住民族歌謠之大端已略備於此。本集歌謠之採集與整理，主要得力於臺北師範學校教諭一條慎三郎君之辛勤耕耘。
大正十四年十一月　臺灣教育會

### 引（前言）

> パイワン族は臺東附近より以南恒春南端に及び主として山地に盤踞し頗る勢力ある蕃族なり。然れども臺東附近の平地に棲むものは農耕を業とし生活狀況アミ族に似たり。彼等の音樂は地方によりて大に其の趣を異にするが如きも本書に收めたるは主として臺東附近のものなるを以て一括して脈絡相通ずるを見るべく、アミ族の歌謠に比して更に素朴なるを知る。彼等亦老若男女手を携へて踊りつゝ高唱し其の狀愛すべし。一條愼三郎君は卑南社 知本社 太麻里社 及び大南社を訪ひて親しく其の歌曲を作譜し苦心の結果本書に收むる所の十三篇を完成せられたり。蓋し最も代表的に且つ最も原形的のものなりとす。尙、東部臺灣の蕃族歌謠としてはパイワン族及び前集アミ族のものゝ外、タイヤル族、ブヌン族のものあり、依りて本集卷末に其の三篇を添へたり。而して此の三篇こそ本島蕃人の歌謠中最も原始的のものなるべし。

**【中譯】**
排灣族分布於臺東附近以南至恆春南端一帶，主要盤踞山間，為頗具勢力之原住民族。然居於臺東附近平地者，以農耕為業，生活樣態與阿美族相近。其音樂雖因地域不同而風趣大異，惟本書所收錄者多出於臺東附近，故通篇觀之脈絡相通，且較阿美族歌謠更顯質樸古拙。彼等亦常老幼男女攜手共舞、引吭高歌，其情態誠為可愛。一條慎三郎君親訪卑南社、知本社、太麻里社及大南社，就地採錄記譜，殫精竭慮，遂成書中所收之十三篇；此皆最具代表性且最存古形之作也。又東部臺灣之原住民族歌謠，除排灣族及前集阿美族之外，尚有泰雅族、布農族之曲調，因於本集卷末附錄三篇；而此三篇，誠可謂本島原住民歌謠中最具原始古風者也。
