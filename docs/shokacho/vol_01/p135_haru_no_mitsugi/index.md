- 出處：《唱歌帳》（國立臺灣歷史博物館典藏號 2020.006.0843）第 P135.jpg 頁剪貼之童謠樂譜。

## 歌詞

```text
一、
みよ、春の日は輝きぬ
野にも山にも牧場にも
こはくの光り美しく
冬のくらきを追ひやりて
琥珀色的陽光多麼美麗，把冬天的陰霾黑暗徹底驅散追逐離去。）

二、
みよ春雨はさゝやきぬ
今ぞ生命のめざめどき
土より出でよ草よ木よ
そゞろも優し銀の糸。
破土而出吧，小草啊、樹木啊！如絲如縷的銀色雨絲是何等溫柔。）
```
