曲目解說與史料考釋：
・出處：昭和五年（1930 年）八月號《臺灣教育》第 337 號第 81 頁〈臺灣の歌審査員の作曲發表〉。
・作歌：上村一仁（全八節歌詞）。
・作曲：一條愼三郎（審查員，採集花蓮港紅座社蕃謠改編）。
・音樂特徵：二降記號（B♭ 大調記譜，實為 C 小調五聲音階 C–E♭–F–G–B♭），2/4 拍，速度 ♩=104，弱起 1/8 拍。樂曲具臺灣阿美族（花蓮港紅座社）呼應歌謠特色，帶有「ヨイ ヨイ」（原譜以「↑」標示喊聲）吶喊呼應與「イヤホホ ホライ」之襯詞唱腔。
・與 1929 年版之異同：1929 年《臺灣の歌》（御大典記念事業發行集）所載之〈南の島〉為中山常雄作曲（ニ調陽音階）；1930 年本版則為一條愼三郎全新改編採譜之蕃謠版本，詞同而曲迥異。
・原刊全八節直排歌詞：
一、冬(ふゆ)がいやなら／南(みなみ)の島(しま)へ ヨイヨイ／雪(ゆき)のない島(しま)／イヤホホ ホライ／春(はる)の島(しま)
二、夢(ゆめ)が見(み)たけりや／南(みなみ)の島(しま)へ ヨイヨイ／椰子(やし)の木(こ)かげで／イヤホホ ホライ／戀(こひ)のゆめ
三、笛(ふえ)が吹(ふ)きたきや／南(みなみ)の島(しま)へ ヨイヨイ／山(やま)に涼風(すゞかぜ)／イヤホホ ホライ／音(ね)もふるふ
四、樂(らく)がしたけりや／南(みなみ)の島(しま)へ ヨイヨイ／牛(うし)の脊(せ)にのりや／イヤホホ ホライ／日(ひ)が暮(く)れる
五、胡弓(こきゆう)ききたきや／南(みなみ)の島(しま)へ ヨイヨイ／絃(いと)のあはれに／イヤホホ ホライ／涙(なみだ)さへ
六、月夜(つきよ)戀(こ)ふなら／南(みなみ)の島(しま)へ ヨイヨイ／遠音(とほね)ちやるめら／イヤホホ ホライ／青(あを)い月(つき)
七、花(はな)を探(さ)ぐるなら／南(みなみ)の島(しま)へ ヨイヨイ／年(ねん)が年(ねん)中(ぢゆう)／イヤホホ ホライ／花(はな)の島(しま)
八、唄(うた)が好(す)きなら／南(みなみ)の島(しま)へ ヨイヨイ／島(しま)が唄(うた)だよ／イヤホホ ホライ／唄(うた)はでも
