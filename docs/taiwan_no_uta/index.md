# 《臺灣の歌》 臺灣教育會御大典記念事業・昭和四年版（國臺圖 0786 8）

> 國立臺灣圖書館「日治時期圖書影像系統」典藏號 **`jpli2011-bk-sxt_0786_8_1929`**（索書號 **`0786 8`**）。昭和 4 年（1929 年）5 月 1 日**臺灣教育會**（臺灣總督府文教局內）作為昭和天皇**御大典記念事業**編纂發行（非賣品，盛文社印刷）。全書匯集昭和 3 年全島公開懸賞募集入選之 **6 首「唱歌」**與 **6 首「臺灣民謠（俚謠）」**共 **12 首**五線譜新曲：卷首第一曲**〈臺灣の歌〉**（内田隆作歌）特委託東京音樂學校教授**信時潔**譜曲並附雙手鋼琴伴奏；唱歌部更收錄臺灣本土音樂家**陳華提**作曲之**〈お祭日〉**與**郭明峯**作曲（附原版雙手鋼琴伴奏）之**〈水牛〉**，民謠部之**〈蓬萊小唄〉**（小松忠文作歌・北川義雄作曲）則附完整「三絃」（三味線）伴奏對照譜。
