# 書訊與卷首／卷末掃描頁 — 《うたのほん》（唱歌課本） 下卷・國民學校初等科第二學年用（2006.006.0878）

本頁收錄本冊之封面、扉頁、目次（もくろく）、樂典大要、版權頁與封底等原書掃描圖檔（共 17 頁）。
