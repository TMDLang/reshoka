## 歌詞

```text
二　白百合の賦

（一）
せゝらぎ清き溪川の
水の流れに影すみて
塵をもとめぬ白百合の
岸邊に笑（ゑ）めり星のごと

（二）
みどり浪うつ夏草の
しげりの上に咲きいでて
姿やさしき白百合の
かをりは高く野にみちぬ

（三）
氣高（けだか）き姿そのまゝを
うつし植ゑなんわが胸に
久遠（くをん）に讃（たゝ）へあこがるゝ
乙女の夢は白百合の花
```
