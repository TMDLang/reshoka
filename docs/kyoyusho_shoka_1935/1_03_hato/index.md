## 說明



- 出處：臺灣總督府編《公學校唱歌》第一學年用，第二課〈ハト〉（鴿子），原書第 4–5 頁（掃描檔 P008.jpg–P009.jpg）。
- 調性與拍號：ヘ長調（F 大調），2/4 拍，速度 != 96。
- 背景與曲風：原出自明治 44 年（1911）文部省《尋常小學唱歌（一）》第二曲〈鳩〉，亦收錄於《新定兒童唱歌》第一學年用第一學期第二首。描寫孩童呼喚鴿子、餵食豆子並看群鴿齊飛的生動情景。
