## 歌詞

```text
九　里心

（一）
笛や太鼓に誘（さそ）はれて
村の祭に來て見れば
日暮はいや／＼里戀し
風吹きや木（こ）の葉の音ばかり

（二）
母（かあ）さん戀しと泣いたれば
どうでもねんねよお泊（とま）りよ
しく／＼お背戸（せど）に出て見れば
空にはあゝかいあかね雲

（三）
雁（かり）々（／＼）鍵（かぎ）になれ棹（さを）になれ
お迎へたのむといふておくれ
```
