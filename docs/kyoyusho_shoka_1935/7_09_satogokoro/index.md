- 調性與拍號：ハ短調（3 降記號，以關係大調 ?= E, 記譜，key= Cm，採 C 都節／陰音階 C–D–Eb–G–Ab），原譜拍號印 C（<4/4> 拍），全曲共 5 行 24 小節。
- 反覆與雙層歌詞結構：第 1–3 行（m.1–16）下方並列印（一）片假名與（二）平假名雙層歌詞，第 16 小節末尾印有反覆記號 `:|`；兩段反覆演唱後接第 4–5 行（m.17–24）第（三）段獨立結尾旋律與單層片假名歌詞。
- 記譜細節保留：第 13 小節第 4 拍四分音符正下方並列印大字拗音「キヤ」（對應底欄「風吹きや」），維持單槽原貌；第 23 小節第 1 拍四分音符正下方印「イッ」（小字促音「ッ」；底欄全文印作「いふておくれ」），依「所見即所得」維持單槽原印字貌。


## 歌詞

```text
九　里心

（一）
笛や太鼓に誘（さそ）はれて
村の祭に來て見れば
日暮はいや／＼里戀し
風吹きや木（こ）の葉の音ばかり

（二）
母（かあ）さん戀しと泣いたれば
どうでもねんねよお泊（とま）りよ
しく／＼お背戸（せど）に出て見れば
空にはあゝかいあかね雲

（三）
雁（かり）々（／＼）鍵（かぎ）になれ棹（さを）になれ
お迎へたのむといふておくれ
出處考證：本曲為北原白秋作詞、山田耕筰作曲之思鄉藝術歌曲/童謠。全曲以 C 小調寫成，充滿深沉哀愁美感，收錄於女子青年部作為修養歌曲。
```
