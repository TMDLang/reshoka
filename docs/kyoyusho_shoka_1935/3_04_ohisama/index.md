## 歌詞

```text
（一）
お日樣は東の空を今朝もまた
うすくれなゐに　きれいに染めて
だん／＼赤く　ぼかします

（二）
お日樣は　東の山を今朝もまた
まばゆい光　ぴか／＼させて
ずん／＼高く　のぼります

（三）
お日樣は　春夏秋冬　やすまずに
毎朝早く　きら／＼／＼と
日本（につぽん）ぢゆうを照します
```
