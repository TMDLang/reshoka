```text
一、
お山が暮れた　野が暮れた
かあかあ烏が　ないて來た
さよならさよなら　歸りませう
かあさんのおそばへ　歸りませう

二、
あかりがついた　月が出た
ねんねんねむの葉も　ねてしもた
さよならさよなら　歸りませう
とうさんのおそばへ　歸りませう

三、
お手々をつないで　わになつて
ひいふうみいよで　手をはなせ
おじぎをしてから　かへりませう
さよなら皆さん　歸りませう
```
