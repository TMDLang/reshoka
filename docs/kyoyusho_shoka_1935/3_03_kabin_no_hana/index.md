## 歌詞

```text
一
これ御覽なさい　綺麗な色よ
お家のお庭に　育てたお花

二
いろんなお花よ　赤白黃色
お部屋の花瓶に　すぐ生けませう

三
嬉しや嬉しや　お部屋も綺麗
綺麗なお部屋で　お遊びしませう
出處考證：本曲為大正時期學校唱歌，葛原しげる填詞、採法國民謠曲調，描繪典雅溫馨的教室生活景況。
```
