```text

風よ吹け吹け　南の風よ
いつも春風　南（みなみ）風
若い心に南風を受けて
さあさ　のばさうよ　島の國

（二）
花よ咲け咲け　高砂島は

（三）
つけよ　つけつけ　大もち小もち
いつも心は　まんまると
若い心を一つにこねて
さあさ　かためよう　島の國
```
