## 歌詞

```text
一一　一つとや

一つとや　人のことより我が事を
あやまりなきかと省みよ

二つとや　古きをたづねて新しき
事をも知らるゝ文學べ

三つとや　都田舍のへだてなく
學びの道のひらけゆく

四つとや　世に住む民はすめらぎの
代々の惠みを忘るなよ

五つとや　いとけなきとき學ばずば
老いて悔ゆとも及ぶまじ

六つとや　むぐらの宿に住むとても
忠義の道は忘るまじ

七つとや　何より大事は親の恩
報いもせずしてすむものか

八つとや　柳は風にも折れはせず
たをやかなるこそ女子の德

九つとや　こらへがたきをこらふれば
こらへられざることはなし

十とや　遠き所へ行かんにも
足もとよりぞはじむなれ
```
