## 歌詞

```text
一、
乘れ乘れ乘れ、竹馬に、
今より後、人となり、
千萬里の、騎馬旅行、
なさん時の、下練習。

二、
のれのれのれ、竹馬に、
今より後、人となり、
わが日本に、向ふ敵、
撃たん時の、下練習。

三、
のれのれのれ、竹馬に、
たれかはよき、のりてなる、
よく騎るものは、一軍の、
大將としも、あふがれん。
```
