## 說明

註記：第一學期第七曲。分節歌，二節同一旋律。開頭標 mf。第四行第二小節（第十四小節）「6. 6_」與「5 6」各有圓滑線（配字「サーマー」／「さーまー」）。右頁「おほぞらの」之「お」以變體假名（𛀙）排印。五線譜與簡譜一致。
