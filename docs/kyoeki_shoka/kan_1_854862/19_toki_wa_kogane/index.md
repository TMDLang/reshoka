## 歌詞

```text
一、
一秒時をも、惜まむ人の、
身にぞ黃金は、つもるべき、
やよや人々、用ゐてつきぬ、
時はこがねの、母なるぞ。

二、
たゞ時の間も、あだにすごさぬ、
人にぞほまれは、やどるべき、
やよや人々、用ゐてつきぬ、
時はほまれの、父なるぞ。
```
