## 歌詞

```text
一、
古鞋くはへて、えたりがほに、
めぐりつはしりつ、狂ふ小犬、
いかにもたのしき、さまのみゆる、
われらも愉快に、いざあそばん。

二、
ひと聲ふた聲、いさみほえて、
進みつしりぞきつ、さわぐ小犬、
いかにもうれしき、さまのみゆる、
われらもゆかいに、いざあそばん。
```
