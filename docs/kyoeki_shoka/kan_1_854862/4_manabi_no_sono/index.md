## 歌詞

```text
一、
友と中よく、打ちつれだちて、
通ふもうれし、學びの園に、
園につみたる、教への草葉、
いかで忘れん、花さく日まで。

二、
友とたのしく、打ちつれだちて、
いづるもうれし、遊歩の庭に、
習ひし唱歌の、ふしおもしろく、
いざや歌はん、もろ聲あげて。

三、
學ぶも友と、へだてぬ窓よ、
遊ぶも友と、へだてぬ園よ、
園なる芝の、緑は常磐、
われらが中も、かはらじ常に。
```
