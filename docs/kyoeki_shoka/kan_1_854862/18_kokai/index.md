## 歌詞

```text
一、
波をけやぶり、くる船は、
大砲もたぬ、軍艦か、
いなとよあれは、萬國に、
ゆきゝたえせぬ、商船ぞ。

二、
國の産物、つみいだし、
よその産物、はこび來て、
交易ひらき、民すゝむ、
皆商船の、たまものぞ。

三、
海を渡りて、見もしらぬ、
土地に旅する、愉快さを、
のせつゝ走る、商船は、
實にこそ國の、寶なれ。
```
