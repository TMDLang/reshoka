## 歌詞

```text
一、
すゞめの鳴く聲、八千代ときこえ、
庭なる松風、萬歳とひゞく。
たのし、たのし、
けふの、祝ひ。

二、
朝日の御旗は、門なみなびき、
唱歌の聲々、里ごとみてり。
たのし、たのし、
けふの、祝ひ。

三、
いざ〳〵われらも、手に手をとりて、
いはひて遊ばん、うれしきけふを。
たのし、たのし、
けふの、祝ひ。
```
