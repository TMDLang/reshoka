## 歌詞

```text
一、
かすみのころも、ぬぎかけて、
のぼるあさ日に、にほふなる、
さくらのはなは、うるはしや、
ゑみのくちびる、ひらきつゝ。

二、
かすみのきぬを、まとひかけ、
ゆふ日なゝめに、かざすなる、
さくらの花は、うるはしや、
ゑみのまゆずみ、こまやかに。
```
