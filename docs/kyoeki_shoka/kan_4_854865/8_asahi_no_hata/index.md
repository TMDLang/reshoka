## 歌詞

```text
一、
廣き世界の、津々浦々、
めぐる軍艦の、マストの上、
潮風に、ひらめきて、
國光あぐる、朝日のはた。

二、
千軍萬馬の、戰の場、
たゝかふ兵士が、つるぎの前、
腥風に、ひらめきて、
國威かゝぐる、朝日のはた。

三、
わが日本の、果てよりはて、
つらなる家居の、軒べ門べ、
朝風に、ひらめきて、
泰平しめす、朝日のはた。
```
