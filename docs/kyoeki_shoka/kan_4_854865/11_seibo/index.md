## 說明

## 歌詞

```text
一、
矢よりも早く、過ぎ行きし、
今年は何を、なしつるぞ、
花にもみぢに、遊びしも、
昨日か今日の、よーなるに。

二、
一夜あけなば、新玉の、
年たちかへり、望みある、
時のきたらん、うれしさを、
こよひは待ちて、あかさまし。

三、
今年は舟を、やらざりし、
學の海も、明日は見ん、
吹かば吹け〲、さよ嵐、
進めや勇氣を、かぢとして。
```
