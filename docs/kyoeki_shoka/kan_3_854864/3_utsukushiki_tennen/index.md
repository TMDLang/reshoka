## 說明

原書資訊與歌詞全文（NDL PID 854864《唱歌教科書 教師用 巻三》第六～七頁，掃描 P009.jpg）：
調性與拍號：と調四分ノ四拍子（G 大調 4/4 拍），♩=126，「スラリト」
註記：單聲部，三節分節歌，開頭 mf。五線譜與下方簡譜一致為 G 大調（起音 D4–D4–G4–G4，即 5_–5_–1–1，音域 D4–E5）。
原典曲意：「此歌は、春の花、秋の紅葉、夏の月、冬の雪、山の綠、水の流れを始め、自然の景色一として我等を喜ばせぬものはないといふ意。」
原典語釋：「すなご」：砂のこと；「またと來じ」：再びこぬであらう。

## 歌詞

```text
一、
げにうつくしき、あめつちの、
四時のながめの、おもしろや、
春は花さく、梅さくら、
秋は綾織る、色紅葉、
夏はすゞしく、月てりて、
冬は玉ちる、雪ぞふる。

二、
げにうつくしき、あめつちの、
四方のけしきの、うるはしや、
山はみどりに、水澄みて、
すなご清らに、松あをし、
あさはたなびく、薄霞、
ゆふべさへづる、鳥の聲。

三、
ながるゝ水は、とゞまらず、
すぎゆく年は、またと來じ、
あそべ人々うつくしき、この天然の四つの時、
ゆけや人々うつくしき、この天然の海や山。
```
