## 歌詞

```text
一、
粗末にすなと、母上の、
おほせ給ひし、此人形、
着物をきせて、帶しめて、
箱の御殿に、すはらせん。

二、
着物はみどり、帶は赤、
模樣は松に、こぼれ梅、
泣くなよ泣くな、お休みの、
日には花見に、つれ行かん。

三、
あばれるねずみ、じゃれる猫、
人形の家を、やぶるなよ、
學校すみて、歸るまで、
待てや我身を、おとなしく。
```
