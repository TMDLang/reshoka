# 赤尾寅吉編《拔萃兒童唱歌集》（昭和8年新竹州音樂講習會）

本專題收錄**國立臺灣歷史博物館（NMTH）**典藏之日治時期重要音樂教育實體文獻——**赤尾寅吉編《拔萃兒童唱歌集》（館藏號 `2020.006.0850`）**。

本書為昭和 8 年（1933）8 月間，臺北第三高等女學校教諭**赤尾寅吉**應新竹州地方之邀，於**中壢公學校**與**竹南郡聯合青年團**等音樂教育講習活動中，所彙整印行之實體講義歌本，為日治後期臺灣地方市街公學校唱歌教學與青年團音樂普及活動的重要第一手實物史料。

### 封面細部特徵考證
- **封面題字**：中央清晰印有四行直排楷體大字：
  ```
  拔萃
  兒童唱歌集
  音樂講習會
  昭和八年
  赤尾寅吉編
  ```
- **插圖藝術**：正上方繪有一位身著優雅洋裝之少女側身彈奏黑色平台三角鋼琴（Grand Piano），展現 1930 年代現代西洋音樂教育在臺灣之視覺形象。
- **厚度與裝訂**：厚度達 2.1 公分、重達 390.5 公克，以日式四孔線裝成冊，內頁用紙紮實，收錄曲目極為龐大。

## 三、編者赤尾寅吉與新竹州音樂講習活動脈絡

### 1. 編者赤尾寅吉之身分
**赤尾寅吉**（1878–？，日本長野縣人）畢業於東京音樂學校，大正 5 年（1916）應聘來臺，長年擔任**臺灣總督府臺北州立第三高等女學校**（今臺北市立中山女高）之音樂教諭與囑託，為該校校歌之作曲者。他與臺北第一師範的一條慎三郎同為長野縣同鄉兼東京音樂學校校友，共同主導了 1920–1930 年代臺灣公學校與中等學校的音樂教育體系，並擔任臺灣總督府公學校唱歌科教材調查委員。

### 2. 新竹州地方公學校與青年團之講習脈絡
從臺史博詮釋資料中的核心關鍵字——**「新竹州」、「中壢公學校」、「竹南郡聯合青年團」**，可以清晰確立本教材的實際使用場域：
- **暑期在職講習與青年團訓練**：  
  昭和 8 年（1933）夏季，新竹州教育會與竹南郡聯合青年團在中壢公學校等地舉辦地方音樂講習會，聘請中央級名師赤尾寅吉編印此講義，專門針對新竹州平地街庄公學校的在職教師、以及地方青年團骨幹成員進行密集的唱歌與舞蹈律動教授。
- **同批文物 `2020.006.0851` 之佐證**：  
  在講習會結束後的昭和 8 年（1933）8 月 27 日，竹南郡矯風會隨即主辦了大型的「音樂舞蹈晚會」，其節目單（`2020.006.0851`）上的曲目正是學員在此講習會中受訓後的實踐成果。

## 四、歷史價值與典藏意義

1. **臺灣公學校與社會教育音樂教材之珍貴實物**：  
   日治時期地方講習會所使用的教材多為臨時性油印或平裝印本，歷經戰火與歲月極難完整保存。《拔萃兒童唱歌集》以厚達兩公分之規模完整留存，是研究 1930 年代臺灣地方基層公學校唱歌教學與青年團文康活動極為稀有的實體見證。
2. **反映地方公學校教師對補充教材之迫切需求**：  
   在大正版《公學校唱歌集》（1915）使用近二十年、而新版《公學校唱歌》（1934）尚未正式推出的過渡期，地方教育界迫切需要吸納日本內地新童謠與現代舞蹈遊戲教材，赤尾寅吉此本「拔萃集」正是當時公學校現場重要的補充教材。
3. **同批文物之全景互證**：  
   本件文物與老松公學校訓導楊金土手抄《唱歌帖》（`2020.006.0843`）、《新定兒童唱歌》（`2020.006.0847`–`0849`）同於 2021 年同一批登錄於臺史博，共同構成了 1920–1930 年代北臺灣及新竹州學校音樂教育最鮮活生動的實物拼圖。
