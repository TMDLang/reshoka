## 歌詞

```text
一、
垣根の川に魚躍り
軒端の山に鳥遊び
浮べる雲は數へみず
求めぬ友も余りあり
二、
峰には開く春の繭
岸には撓る苔の檜
盡きせぬ眺め山深く
憂き世の事も見づあはし
```
