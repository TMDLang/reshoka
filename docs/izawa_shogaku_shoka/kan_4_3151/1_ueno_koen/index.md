## 歌詞

```text
一、
山杜鵑（やまほととぎす）血に啼きて
其五月雨（そのさみだれ）の暗き夜も
今は昔の物語り
忍が岡こそをかしけれ
二、
紅葉よ花よ都人の
車も絶えず集ひ來て
雲の上野に袖かへて
君が御代こそ樂しけれ
```
