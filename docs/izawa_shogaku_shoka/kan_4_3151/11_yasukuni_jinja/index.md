## 歌詞

```text
一、
明治の御代の治まりて
都も鄙も近づきぬ
思ひつづけて語らひも
乱れし世こそゆくへなれ
二、
御國の爲に潰し身は
安き靖國に
いつくの神と鎮まりて
後の世までも照らすなり
三、
事あるときは誰れも皆
命をすてて君の爲
同じく神と祀られて
後代までも安く守るべき
```
