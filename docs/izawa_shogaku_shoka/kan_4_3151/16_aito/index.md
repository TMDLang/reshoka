## 歌詞

```text
一、
かたみの鐘よなみだの種と
知るや知らずや君小夜の空
見よつけし手にとり持ちて教へられし
君にいま別れて
二、
學乃道には親とたのむ
忘られぬ情とつらきこの別れ
君といま別れて
三、
あすは殘るかたみの友を見よ
ふけぬ夜もお連れ立ちて續ける友の
君にいま別れて
```
