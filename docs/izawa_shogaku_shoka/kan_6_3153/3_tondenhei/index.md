## 歌詞

```text
一、
果ても限も蝦夷が島
国の富をば増す為と
開き拓く田の面にも
猛き心は屯田兵

二、
事あり起らばつるぎ太刀
執りて奮ひて夷等に
見せん強氣北の武士
いざや勇めよ屯田兵
```
