## 歌詞

```text
一、
神代の昔も 明治の今も
かはらぬ皇統の 我が大帝
うごかぬをしへの 三種のたから
仰げやもろ人 よろづ世までも

二、
木々の花咲く さかひを分ちめ
うるほふ人の こころのどけさ
すめらぎのみよゝ ながきさかゆく
日のもとよきこと 異国までも
```
