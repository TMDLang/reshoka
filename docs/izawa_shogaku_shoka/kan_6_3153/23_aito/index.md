## 歌詞

```text
一、
形見の言に 泣けど乱れの
種と知りつつも なほ呼ぶ
學びの道 親と頼む
君にいま別れて

二、
忘れぬ心に 泣ける乱れし
友と見つゝにつけ 又泣く
面影持ちて 教へられし
君にいま別れて

三、
名残の霞の 文見るにつけ
又泣きて 讀みし友の
此の世を去りし君
君にいま別れて
```
