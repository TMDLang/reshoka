## 歌詞

```text
一、
日数をかさね年を積み
学びの庭に踏みならし
物の理人の道
導き給ひし師の恩を
いかで忘れん吾が忘れめや

二、
学の庭に年を積み
朝夕ともに学びえし
もののことわり人の道
一つにつくして国恩を
いかで酬いんいで酬いまし
```
