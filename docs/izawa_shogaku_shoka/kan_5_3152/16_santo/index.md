## 歌詞

```text
一、
むかし男乃そのかみの
なら名におほす都鳥
いまぞまことの都鳥

二、
柳のたてと花のそで
夕るる春のみやこの
かすむをめづらに鳴く鳥
春のかすみに鳴く鳥

三、
出づる百船いる千船
高津の宮のむかしより
今もかはらぬ浪のはな
浪のはなの音せぬひまもなし
```
