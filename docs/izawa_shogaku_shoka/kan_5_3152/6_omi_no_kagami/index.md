## 歌詞

```text
一、楠公
七たび八回生きかへり
死にかへりても大君の
御楯となりし楠木ぞ
世々の鑑となりぬる

二、名和長年
よする波風の荒磯に
こころ砕きます君を
御船の上に迎へ奉りて
世にたぐひなき功績あり

三、兒島高德
謀りし事はかひなくて
舟坂山を杉坂を
空しくすぎし行宮の
庭の桜の花伐りて

四、小楠公
別れし父の言となり
いさめし母の心操
たつた桜の暇乞ひ
かたひき矢ぞあはれなる
```
