## 歌詞

```text
一、
あきのみやまのおく深く
照る月かげは明けき
わが君が代にひときはの
ひかりをそふる鏡あり

二、
その月かげのさすところ
その日をとへば地久節
千世よろづよと九重の
うちも外にも響くらむ

三、
たかきいやしき少女らが
まことの道にすぐむべき
學のわざのあきらかに
あれも君がみかげあり
```
