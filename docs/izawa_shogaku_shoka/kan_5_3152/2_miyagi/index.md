## 歌詞

```text
一、
いそのかみのふるつぎ
御柱ふとくたてつなぎ
萬代までも動かじと
たてまつりて造るらむや

二、
明治の春のもとなちまり
ふさぎせといふ年乃末
うつりてませる高みくら
千代をちぎりて榮ゆらん

三、
動かぬよの宮ばしら
たれか仰ぎまつらざる
御稜威高き寶田の
千代田の空に香のくや
```
