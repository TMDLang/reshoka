## 歌詞

```text
一、
天津日影もくもらぬに　世のうき雲のゆきかいに
晴れと曇りと定まらで　君に憂ひをかけまつる
時は風にも雲吹き拂ひ　豊榮のぼる御光を仰ぐ
御代こそ樂しけれ　君も千代ませ八千代ませ

二、
大和錦のうちしきを　ひよろにすこやかやすくたてゝ
ひたぐひなき光ますゝゝ　そひぬべく
聞きたまふくのもろゝの　學の道に勵む業も
並び進みて日に行榮れゝ　御代こそ樂しけれ
君も千代ませ八千代ませ

三、
萬の國もへだてなく　港のとざし開きなば
八重波海のきりもなく　廣き御心になひつつ
大船をつらね國つもの　續ゝ運びめぐらしめ
民の懐をたちをひて　賑ふところぞ樂しけれ
君も千代ませ八千代ませ

四、
惠の露のかゝらずば　民草いかで榮ゆべき
この大昭代に生れずば　このさちいかで得らるべき
身の譽も榮れ戸々　君大君の萬代に
祝へるかづきとぐゝしく　今日こそ樂しけれ
君も千代ませ八千代ませ
```
