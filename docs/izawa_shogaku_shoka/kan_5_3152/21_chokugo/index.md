## 歌詞

```text
一、
千代田の宮居に心をかけて
世をしろしめす大君の
くだし給へる勅語によろづの民は萬世も
踏み違へじと行くべき道ぞ畏らき

二、
ひとりの君とおほくて二人の親とうやまひて
いほせ同胞友がきと睦びあひつ御教を
守りそむかず願はし達ちぬ誠あらせん

三、
瑞穗の國の民として大日本に名を負ひて
臣とならば君をまもり民のものとすぐむべき
仰ぎまつらん春の日も備へてありなん秋の夜も
```
