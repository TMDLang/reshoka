## 歌詞

```text
一、
明治の御世の太平を
みやこにひらきまつらんと
ありつる君がみたまの
宮こそここに建ちぬれ

二、
君とふ民のふかき身乃
いのちを捨てて死ににける
いのちのうちは若くとも
のちの世永くてらすなり

三、
死にける君の御霊たち
み国を守りて千代八千代
御代をやすくまもりませ
```
