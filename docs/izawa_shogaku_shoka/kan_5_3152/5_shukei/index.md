## 歌詞

```text
一、
見渡せば野邊の秋萩
咲き亂れ草木を敷き
吹く風薫りておく霜白く
見渡せば野邊の秋景色

二、
打群れて山の秋風
高嶺より紅葉を散らし
麓を照らすは日本繪と見紛す
見渡せば山の秋景色
```
