## 歌詞

```text
一、
垣根の川に魚躍り
軒端の山に鳥遊ぶ
浮べる雲いふこと見えず
水のみ、岩の小鉾あり

二、
峯のひらきし花の眉
岸に八重咲く若の髭
盡せぬながめ山深く
浮世のありひな忘れし
```
