一、一つとや、ひゞ生れて忠孝を　かさねて皇國の人であれ

三、三つとや、みな〳〵日々そだちて　うれしく學ぶも親のおん
四、四つとや、よみかき算盤よく覺え　體操唱歌も習ふべし
五、五つとや、いつもたゆまず先生乃　教の言葉をよく守れ
六、六つとや、無病で勉強卒業し　あつぱれよき子といはるべし

九、九つとや、この身のもとたる父母の　名をもならはせ名をあげて
十、十とや、とほくに人にあふぐまで　皇國のほまれをあげよかし

(注意) 此歌ハ、學童ニ、國家教育ノ旨意ヲ知ラシメンガ爲メ、作レルモノニシテ、先ヅ忠孝ヨリ、始メ、家族、朋友、及師弟間ノ道德ニ及ボシ、次ニ勸學修習ノ要ヲ示シ、終ニ國家ニ對スル心得ヲ述ベタルナリ。
