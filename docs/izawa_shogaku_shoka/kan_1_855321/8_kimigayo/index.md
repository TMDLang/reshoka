```text

君が代は
ちよにやちよに
さざれいしの
いはほとなりて
こけのむすまで

注意（原書說明）：
(注意) 此歌ハ、古今集ノ古歌ニ、「わが君ハ、千代に八千代に、さざれ石の、いはほとなりて、苔のむすまで」トアルヲ、或ル唄トモ、君が代ハ、千世に八千世に、ト云フト吹メテ、用ヒ來リタルヲ、終ニ其樂譜ヲ作リテ、天皇陛下ノ萬歳ヲ祝スルノ歌曲ト作シタルモノナリ。
此曲ハ、今日殆ド我國歌トシテ、祝日祭日ナドニ、一般ニ用ヒラル、コト、ナレリ。故ニ何レノ學校ニ於テモ、能ク習熟セシメンコトヲ要ス。
```
