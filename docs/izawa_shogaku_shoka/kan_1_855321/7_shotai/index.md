## 歌詞

```text
一、
小隊右むけ一二三
せうたい進めや一二三
小隊とまれや一二三
がうれい守れやよき武士

二、
小隊なほれや一二三
きやうだう左へ一二三
せうたい休めや一二三
ゆだんをするなよよき武士

注意（原書說明）：
(注意) 我國ハ古ヨリ武ヲ尚ブ國柄ニシテ、今日全國皆兵ノ制アルコトナレバ、幼少ノ時ヨリ、軍事ニ心掛アラシムルコト肝要ナリ。故ニ兵役ノ事ナド常ニ説キ聞カスベシ。此歌其補ニモナレカシトテ、作レルナリ。又此曲ノ旋律ハ、君が代ノ曲ニ類似シタレバ、全曲ヲ授クルノ豫備トモナルベキモノナリ。
此樂譜ハ、祝祭日其ノ他、生徒、講堂ニ出入スル時ナドノ進行曲ニモ、用フベキモノナリ。
```
